从 Harness 自我改进到模型权重更新：一次 SIA 复现实践

Johnson7788（2026-11-18）复现 SIA 论文（arXiv:2605.27276）：Harness 自我改进 + 权重更新双循环，Qwen3-8B + deepseek-v4-pro 在 GPQA 上实测；Harness Gen 2 改动反而退化、权重单更新不稳定、两者结合在 40 题上 62.5%→80% 但 p=0.1213 未达显著——罕见诚实的复现日记，LoRA 参数、失败分析与工程踩坑全给齐了。Agent harness 与自蒸馏实战，值得慢读。

大纲

SIA 是什么

  • 双循环：Harness 改进 + 权重更新
  • 反馈模型分析失败 → 提 Harness 改动；筛出的轨迹用作训练数据
  • 复现三问：反馈模型能否定位真问题；轨迹训练能否稳定提分；两者结合是否优于单用
  • 来源论文：SIA: Self Improving AI with Harness & Weight Updates（arXiv:2605.27276）

实验设置

  • 硬件与模型：A800-SXM4-80GB；目标 Qwen3-8B；反馈模型 deepseek-v4-pro
  • 任务：GPQA（198 题）与 LawBench
  • 权重更新：LoRA SFT，拒绝采样自蒸馏
  • rank 16 / alpha 32 / dropout 0；可训参数 43,646,976（~0.53%）
  • 3 epoch，lr 1.5e-5，seq 8192，paged_adamw_8bit；81 步，6 分 36 秒，终 loss 0.10–0.16
  • 训练数据：109 条 = 69 条正确 Gen-1 轨迹 + 40 条教师解法
  • 防泄漏：教师只见题面不见答案，事后程序校验
  • 教师单次 59.5%（44/74），5 次升温采样后 70.3%（52/74）

Harness 阶段：Gen 2 反而退化

  • Gen 1：87 对 / 95 错 / 16 未答，准确率 43.94%；物理 57.0%、生物 57.9%、化学 29.0%
  • 主因：严格 JSON 输出失败——推理常超 3.1 万字符，8192 token 上限内到不了 JSON；并发长生成超时
  • Gen 2“修复”翻车：关 thinking、强制 JSON、加续写 → 正确 87→36，未答 16→147，准确率 43.94%→18.18%
  • 评估陷阱：Gen 2 的 70.59% 是 correct/(correct+incorrect)，排除了未答题
  • 续写还把吞吐从约 1.8 题/分钟拖到约 0.1
  • 教训：Harness 改动先小样本验证；汇报必须含总题数、已答、未答与全量准确率

权重阶段：单更新不稳定

  • Qwen2.5-3B / LawBench：18.95%→26.83%（+7.88pp，p<0.01）
  • Qwen3-8B / GPQA：多配置无稳定提升
  • ORPO 反例：教师格式数据把平均生成从 8192 token 压到 819 token，准确率 65%→50%；STEM + 难度感知数据更跌到 32.5%
  • 解释：模型学了模仿/压缩格式，丢了难题所需的推理

结合：有信号，未证实

  • 同 40 道 held-out 题、同解析器：基线 + disciplined 提示 25/40（62.5%）→ 结合模型 + disciplined 32/40（80%）
  • 但 McNemar χ²=2.400，p=0.1213，未达显著；11 题改对、4 题改错，净 +7
  • 提示依赖：结构化控制标签在 disciplined 提示下用 92.5%，普通 CoT 下 0%——是条件激活而非内化
  • 对照 D-CoT 论文用了 5,079 例，本复现仅 109 例，不可直接比

工程踩坑实录

  • 环境：无 sudo、Xcode 许可挡 Git、缺 CA 证书、GitHub 超时走代理/镜像
  • 框架：transformers 4.48 不认 Qwen3（升 4.51.3）；trl 0.12.2 无 GRPO（升 0.16.1）
  • 训练：LoRA 参数须显式 requires_grad_(True) 才有梯度；右侧 padding 破坏批量生成，改左侧
  • 数据与服务：教师 JSON 截断（max_tokens 4000→24000）、未转义控制字符、并发提速 4→155 题/分钟、runs 目录已存在致 SIA 退出、服务重启抹掉整批评估、双进程抢约 71GB 显存改串行

作者结论

  • Harness 改善执行与输出完整性，不增加模型知识
  • 轨迹数据质量与分布重于数量
  • 结合有正信号但样本太小；下一步：更大独立评估、扩展 LawBench、加 RAG/外部高质量数据、换更大基座
