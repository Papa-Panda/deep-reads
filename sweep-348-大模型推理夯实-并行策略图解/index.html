大模型推理夯实：并行策略图解

科英（2026-05-09，491 赞 / 1402 收藏）把推理并行 7 种策略 TP、PP、DP、EP、DP Attention、SP、CP 按权重 / 批次 / 序列 / 层四个切分维度一次讲透，每种都按「切什么、在哪通信、何时用」展开，并对照 SGLang / vLLM 源码（2026-05-05）讲清 DP+EP 语义分歧与 DP Attention 的真相；正撞推理优化与 MoE 部署主线，适合当作并行策略的案头手册。文中通信量均为量级估算，非实测基准。

大纲

大纲（全文已通读；科英，2026-05-09；基于 SGLang / vLLM 源码 2026-05-05，数字为量级估算）

  • 总框架：7 种策略按切分维度分 4 组，四维正交可叠加
  • 权重：TP、EP；批次：DP、DP Attention；序列：SP、CP；层深：PP
  • 推理并行的三个目标：装得下（模型 + KV）、跑得快（prefill 吞吐 / decode 延迟）、通信不成瓶颈（尤其跨节点）
  • TP 张量并行：按 hidden 维切权重矩阵
  • 列切分出分片输出、行切分出部分输出，列→行成对出现，每层只需在块尾通信一次
  • 每层 2 次 AllReduce（Attention 后 + MLP 后）；单次约 1.5GB，80 层一次前向约 240GB（B=32、S=2000、H=8192、TP=4 估算）
  • 必须留在 NVLink 域内（TP 通常 ≤8）；decode 时 S=1，通信量小但延迟主导
  • GQA 下 TP 超过 KV 头数会复制 KV 头，KV cache 膨胀
  • PP 流水线并行：按层切，层内不切
  • 每 stage 边界只有一次 P2P（约 1GB），通信量最小、最跨节点友好
  • 代价是流水气泡：气泡率 (P-1)/(M+P-1)，micro-batch 摊薄；decode 时单请求延迟 = 各 stage 之和
  • 典型组合：大 dense 模型 TP（节点内）× PP（跨节点）× DP（外层）；MoE 再叠 EP
  • DP 数据并行：整模型复制，分请求
  • 前向零通信，吞吐线性 ×N；但不解决装不下的问题，须叠加 TP/PP/EP
  • EP 专家并行：MoE 专家分片，每层 2 次 A2A（dispatch + combine）
  • 关键技巧：AllReduce ≡ ReduceScatter + AllGather，把 AR 拆成两半、中间夹 MoE，省掉 4 倍冗余 dispatch 流量
  • moe_tp=1（DeepSeek 式多小专家，专家整存）vs moe_tp>1（Mixtral 式少大专家，专家内再切）
  • 陷阱：同样 --tp/--dp/--ep 在 SGLang 与 vLLM 语义不同，SGLang 须开 --enable-dp-attention 才把 DP 变成真并行维
  • DP Attention：Attention 保小 TP，MoE 放大 EP
  • 三方案对比：纯 DP（专家 GEMM 欠填）、全 world TP（Attention 绑死 MoE）、DP Attention（attn_tp=4 + EP=16，正交）
  • 硬收益：256 专家模型 EP=4 时每卡 64 专家约 96GB 装不进 80GB 卡，EP=16 时 16 专家约 24GB 才装下
  • 正名：SGLang 的 DP Attention 里并无 token↔head 的 A2A，只有 RS + AG 替代 o_proj 后的 AllReduce；名字有误导性
  • SP 序列并行：TP 的激活内存补丁
  • 把 TP 区域外的 LN/Residual 激活也按序列切，每层省 1.5GB 激活（2GB→512MB）
  • 代价：集合通信 2 次变 4 次、字节数不变；推理价值小（激活用完即弃），训练与长 prompt prefill 价值大
  • CP 上下文并行：序列切进 Attention 内部，专治 32K+ 超长上下文
  • SP 只切 Attention 外的激活，CP 用 Ring Attention 切 Attention 内的 K/V，是独立维度
  • Zigzag 切分：一卡一早一晚两段 chunk，(r+1)+(2cp-r)=2cp+1，各卡计算量与 rank 无关
  • 约束：zigzag 要求每 DP rank batch=1、只用于 prefill；round-robin 只配 NSA 核
  • CP + MoE：MOE_DP 是 ATTN_CP 的别名，进 MoE 前先合 token、出 MoE 后再拆
  • 速查表：TP 切 hidden 维 / PP 切层 / DP 切 batch / EP 切专家 / DP Attention 切 head / SP 切 Attention 外序列 / CP 切 Attention 内序列
