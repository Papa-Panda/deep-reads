# Karpathy 的 autoresearch 搬进搜广推，我发现最难的不是自驱动，是交付对齐

> GuoXun（百度）把 Karpathy 的 autoresearch 自驱动实验范式搬进搜广推，开源 AlgoPilot：离线棘轮跑得快，但 AUC 只是线上 CTR/GMV 的代理指标，作者补了「交付关」端到端仿真与「兑现率」台账，量化出同样是保留事件、交付价值能差 40 倍；自驱动 Agent + 交付对齐，正撞他的 Agent RL 与 infra 主线。注：推荐流标题称「用 o3」，正文未提 o3，实验用的是确定性 mock 引擎。
