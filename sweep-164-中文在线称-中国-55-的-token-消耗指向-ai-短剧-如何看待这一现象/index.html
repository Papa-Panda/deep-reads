中文在线称，中国 55% 的 token 消耗指向 AI 短剧，如何看待这一现象？

知乎热榜第 1（约 546 万热度，226 个回答，约 62 万浏览）。中文在线 2026 年 6 月机构交流披露的中国 token 消耗构成出人意料：AI 短剧与视频生成占 55%、电商营销 24%，被寄予厚望的软件开发（vibe coding）只有 15%。头部回答（323 赞）给出了机制解释：视频 token 是按时长计的——720p 约 2 万 token/秒，一个 5 秒镜头约等于一部 10 万字剧本的量，加上反复重抽，成品轻松到数亿 token，所以 55% 甚至偏低；但他同时提醒，token 份额不等于算力、收入或价值份额，视频 token 定价完全不同。对他的价值在推理需求结构：若需求大头在内容生成而非编程与 agent，推理 infra 的优化重心（视频/多模态吞吐）就要跟着改。数据须打折：55% 是单一公司披露、无统计口径，披露方本身做 AI 短剧。注：已读默认排序前 3 答（最高赞 495 的是短讽刺答，机制答在第二）。

大纲

大纲（据默认排序前 3 答与公开报道整理）

  • 数据本体（中文在线 2026-06 机构交流披露）
  • 国内 token 消耗构成：AI 短剧与视频生成 55%、电商与营销 24%、软件开发约 15%
  • 问题页 226 个回答、约 62 万浏览、热榜约 546 万热度
  • 背景量级：国家数据局口径，2026 年 3 月中国日均 token 调用量已突破 140 万亿，较 2024 年初增长超千倍
  • 机制解释：视频 token 按时长计（约 323 赞）
  • 720p 视频约 2 万 token/秒，一个 5 秒镜头约等于一部 10 万字剧本的 token 量
  • 制作中反复重抽，单部成品轻松达到数亿 token；视频对文本有 3–4 个数量级的天然放大，55% 甚至偏低
  • 关键区分：token 份额不等于算力份额、收入份额或价值份额，视频 token 的定价与文本完全不同
  • 反应层：最高赞答（495 赞）是短讽刺——质疑题目隐含的价值排序（用 AI 干活高于看 AI 内容），认为闲暇看 AI 视频本就比用 AI 工作更放松
  • 对推理 infra 的含义
  • 需求结构决定优化重心：若大头是视频生成，扩散/多模态推理吞吐、显存与调度比文本 LLM 的 KV 优化更吃重
  • token 经济学要分场景看单价与付费方：内容生成的付费方是平台与广告主，价格弹性与编程订阅不同
  • 数据可信度（先打折再使用）
  • 55% 来自企业单方披露，引用的是未注明出处的行业数据，未说明统计方法与 token 换算标准
  • 披露方本身就是短剧公司，有强调自身赛道的动机；无官方或第三方独立普查佐证
  • 用法：当作需求结构的方向性信号（视频生成是算力黑洞），不要把 55% 当精确份额引用
