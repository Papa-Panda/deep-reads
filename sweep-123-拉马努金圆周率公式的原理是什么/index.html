大纲（据默认排序前 3 答整理）

  • 问题与公式（18 答、147.7 万浏览）
  • 目标：1/π = (2√2/99²) Σ (4k)!/(k!⁴) · (26390k+1103)/396^(4k)，k=1 时即溢出计算器精度，每项约贡献 8 位小数
  • 起点：椭圆积分与超几何的桥（5342 赞、Hyacinth 352 赞）
  • Clausen 公式：₃F₂(1/4,3/4,1/2;1,1;z) = (2K(k)/π)² 型恒等式，π 从 K 的周期比里出现
  • θ 函数、AGM 与 Dedekind η：(2K/π) = θ₃²(q)，模变换给出 q = e^(−πK'/K)
  • 模方程与奇异值：26390 与 1103 的出处
  • K'(k₁)/K(k₁) = n·K'(k₂)/K(k₂) 时 k₁、k₂ 满足代数模方程；取 n=58、q = e^(−π√58)
  • 类不变量（判别式 −232、类数 1、基本单位 (5+√29)/2）给出 c(k) = 1/99⁴ 与 √29 项
  • Guillera 式对乘子求导定出 a、b，正好拼成 26390k+1103（Hyacinth 答给出 α₀、m₀ 的完整代入）
  • 三条读法
  • 5342 赞答主：Borwein 兄弟路线，复乘 + Kronecker 极限公式，最深最硬
  • Hyacinth：四次理论 + J 不变量的现代重写，常数来源最清楚
  • Eliauk（75 赞）：先用三次模方程手算 4/π 原型再推广到 58，最适合入门跟算
