# 长鑫科技股价跳水，市值跌破 3 万亿元，前三季度预赚 1300 多亿还推出回购，为什么股价反而大跌？

> 知乎热榜条目（约 116 万热度、24 个回答、约 7.1 万浏览）。表面悖论：长鑫科技 10 月 19 日盘中跌超 8%、收跌 6.29% 报 42.19 元、市值约 2.86 万亿，而公司预告前三季度净利 1310–1325 亿元扭亏、董事长还提议 10–20 亿元回购。深读高赞回答后，跌因不在 headline 利润而在二阶导：三季度净利 533.95–548.95 亿元、环比二季度 528.43 亿元仅 +1%–3%；DRAM 合约价环比涨幅从一季度 93%–98% 收窄到二季度 58%–63%、三季度仅 13%–18%，而御三家靠 HBM 长约仍有支撑，中低端 DRAM 则是商品化、强周期生意——市场按周期拐点先行重定价，回购规模与用途（员工激励/持股或减资）不足以对冲。对他有用：这是存储周期与估值计入方式的一手分歧样本，正对芯片竞争与价值投资两条线。注：已通读默认排序前 5 个回答，其余 19 个回答页面未加载、未读到。
