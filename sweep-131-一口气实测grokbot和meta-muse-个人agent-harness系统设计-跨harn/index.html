大纲

大纲（据 UP 简介与章节列表整理；该视频字幕轨被 B 站错配，未能取得可靠口播稿）

  • 实测背景：两周使用后追问——比 Claude Code / Codex 多了什么
  • Grok Bot 架构：一账号一台云 VM；多个 Bot 共享浏览器、/workspace、终端与凭据；隔离的是人格而非上下文；教一次任务即沉淀为 skill
  • Meta Muse 架构：一人一台安全 VM、一个 agent；外部 Sentinel agent 管权限与 token；memory.md 可读、可改、可下载
  • 共同底座：VM、连接器、定时任务、审批、记忆（五盒子框架）
  • 记忆对照：Grok Bot 找不到记忆存放处；Muse 有明确的 memory.md
  • 跨 harness 记忆实验：两边都接入 Waku 记忆层（MCP），一句话存入一侧，冷启动新会话在另一侧被召回
  • 开放问题：容器内的 agent 若不可信，为何信任外部 Sentinel？
  • Agentic shopping 中途放弃：亚马逊 UI 是为人设计的，产品应当 agent-native
