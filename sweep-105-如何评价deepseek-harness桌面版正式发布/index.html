如何评价DeepSeek Harness桌面版正式发布？

知乎热榜讨论（18 答、13.4 万浏览）：DeepSeek Harness 桌面版 v0.2.0 正式发布——dsh web 套 Electron 壳、自带 pnpm/Python/Node 完整运行时，新增官方网络搜索、插件市场、插件版本兼容检查与失败 tool_call 恢复机制。高赞实测拆解了安装包结构与平台取舍，路线图指向沙箱安全、智能体团队、长期记忆、Computer-Use；正是他做 Agent RL harness 可直接对照的国产开源实现。

大纲

大纲

  • 事件：DeepSeek Harness 桌面版 v0.2.0 正式发布
  • 版本号从 0.1.7 一跃到 0.2.0；官网直接提供 macOS / Windows 安装包；登录可领 6 元体验金
  • 核心意义：从"面向开发者的公开测试阶段"走向"正式发布阶段"——开箱即用（18 答、13.4 万浏览）
  • 架构实测（Archimon，124 赞）
  • 本质：dsh web 应用外包一层 Electron 壳；本体约 1GB（1144 个文件夹、9772 个文件），不算臃肿
  • 自带完整运行时：独立 pnpm、Python、Node.js 分发包；Python 预装 numpy、pandas、python-docx、python-pptx、openpyxl、Pillow、lxml、XlsxWriter，Office 任务默认走这些库
  • 平台取舍：仅 macOS arm64/x64、Windows x64；README 明确"Linux 不是受支持的 Desktop 发布目标"；受众是 Mac/Windows 日常办公群体
  • 登录类似 Codex（浏览器账号登录）；大陆 IP 顺畅，非大陆 IP 会被卡住（官网只剩粒子特效、无下载链接）
  • 0.2.0 新能力（58 赞回答）
  • 账号体系新能力：网络搜索——DeepSeek 账号登录可调用官方搜索服务，否则需自配搜索 api-key
  • 官方插件市场：目前只支持启用/禁用已安装插件，暂不支持安装/卸载；负责人崔添翼正用个人账号试水推荐社区插件（dsh-tui、DSH-better-sidebar）
  • 稳定性：插件可声明兼容的 DSH 版本，加载前检查版本，不兼容插件被禁用而不拖垮整个 Harness 启动
  • 失败恢复：结束失败任务前给未完成的 tool_call 补齐结果（失败被明确记录），历史 session 不再因缺少 tool_result 而"炸掉"
  • 新增定时任务（做成插件形态）
  • 官方路线图
  • 沙箱安全、智能体团队、长期记忆、Computer-Use
  • 实战派用法（踏雪寻仙，11 赞，开源 argo 作者）
  • 四种模式：标准 / 极简 / PTC 批量处理 / 创造（写插件或复杂新功能）
  • 经验：做 dsh 插件修复/适配最适合的模型是 GLM5.3 flash（便宜稳定，通常 1-2 轮搞定）；skill 和插件可互相替代
  • 元提示词 /code-review：第一性原理 + MECE + 量化思维（源自 Cursor 的 thermo-nuclear-code-quality-review skill）
  • 为什么值得他看
  • 他正在做 Agent RL / harness（今晨 397B Harness 修复笔记、Claude Code 源码拆解）；DeepSeek Harness 是国产开源 agent runtime 的标杆实现，插件版本兼容、tool_call 失败恢复、沙箱路线图都是可直接对照借鉴的工程决策
