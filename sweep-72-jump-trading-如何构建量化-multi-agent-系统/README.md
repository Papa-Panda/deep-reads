# Jump Trading：如何构建量化 Multi-Agent 系统

> Jump Trading 介绍如何把 Multi-Agent 用于量化研究：先从单模型、单 Harness 的最小闭环开始，以真实内部工作流建立 point-in-time eval，防止未来信息泄漏；按任务依赖选择单 Agent、去中心化工具调用或 Orchestrator–Worker；只有在质量、速度、成本或可靠性确有改善时才增加复杂度。AutoResearch 还需预先定义输入、输出、权限、约束与多指标 Scorecard，并保存完整轨迹反复验证。
