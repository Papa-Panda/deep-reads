为什么GRPO很容易训飞，训到一半reward就很容易突然掉下来？

白露未晞me（2026-11-24）用三答案极简模型严格证明：GRPO 的组内相对优势 + 有限采样 + softmax 耦合，会让低于全局均值的平庸解拿到正优势、挤占最优解，G=8 时约 26% 的采样组算错方向；Clip 与 KL 在更新起点拦不住，偏差逐轮累积就是 reward 半路骤降的原因。注：原文链接为浏览器在知乎站内搜索核验后的有效地址（推荐流抓到的旧链接已失效）。

大纲

1. 核心结论：训飞是结构性的，不是 reward 不准

  • 作者白露未晞me（2026-11-24）用数学证明：即使 reward 完全准确，有限组采样 alone 就能让 GRPO 做出降低真实期望奖励的更新
  • PPO Clip 不能保证真实期望奖励单调提升

2. 设定：三答案的极简模型

  • 固定 prompt，只有 a、b、c 三种答案，奖励固定；logits 经 softmax 得概率，真实期望奖励 J = Σ p·r
  • 真实梯度：∂J/∂z_j = p_j (r_j − J)，取决于奖励相对全局均值 J 的高低

3. GRPO 的组内优势：相对的是组，不是全局

  • Â_i = (R_i − 组均值) / (组标准差 + δ)，优势只相对本组采样
  • 关键情形：某组只抽到 a、b（漏掉最优解 c），组内优势之和为零，b 得正优势、a 得负优势

4. 为什么 Clip 和 KL 拦不住

  • 更新起点 π = π_old，ρ = 1 落在 clip 区间内，clip 对梯度无作用
  • KL 参考等于旧策略时，其一阶梯度也为零；有效梯度 ĝ = λ(e_b − e_a)，只推高 b、压低 a

5. 数字例子：错更新长什么样

  • (p_a, p_b, p_c) = (0.1, 0.8, 0.1)，奖励 (0, 1, 4)，J = 1.2
  • 更新后 b 概率上升、最优解 c 概率下降，J 实打实变小
  • G = 8 时约 26.27% 的采样组会产生这种错误方向

6. 直觉版：数学推理模型的三种解法

  • 常错解（0 分）、平庸解（1 分）、满分解（4 分），概率 10%/80%/10%
  • 一组 8 个样本漏掉满分解时，平庸解因高于组均值被奖励，满分解被 softmax 挤占

7. 累积与崩塌

  • 下一轮更难采样到最优解，训练信号进一步萎缩；自回归生成中漂移逐 token 累积
  • 这就是“训到一半 reward 突然掉下来”的机制
