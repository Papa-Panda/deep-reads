Agent Forecast

研究 AI Agent 能否预测事件结果：梳理 ForecastBench、FutureSim、CivBench 三个预测 benchmark，自带 Brier Score 交互实验台，拆解预测 Agent 的工作流程、典型失败模式与可审计的评估 schema。

2026-09-29

原文链接：https://muse.ai/s/agent-forecast-xdxp67xuxixx907r

大纲

核心问题

  • Agent 能否预测事件结果？这不是聊天能力，而是把世界建模成概率分布的能力
  • 预测质量决定了 Agent 在长任务中的资源分配与止损决策

三个 Benchmark

  • ForecastBench：真实世界事件预测，覆盖政治、经济、科技等多领域
  • FutureSim：未来情景模拟，考验多步推理与情景展开
  • CivBench：文明级复杂系统预测，长周期、高不确定性

Brier Score 实验台

  • Brier Score：概率预测的均方误差，越低越好
  • 交互实验：拖动预测概率，实时看分数变化
  • 为什么 Brier Score 是 proper scoring rule：说真话才是最优策略
  • 校准性 vs 锐度：又准又敢是两回事

预测 Agent 的工作流程

  • 信息收集：多源检索，区分事实与观点
  • 假设生成：列出互斥情景
  • 概率校准：用 base rate 锚定，再按证据更新
  • 持续更新：新证据到来时按贝叶斯方式修正

典型失败模式

  • 过度自信：概率推得太极端
  • 锚定：被第一个数字带走
  • 忽视 base rate：小样本故事压倒大数定律
  • 更新不足：证据变了，概率不动

Benchmark 设计清单

  • 可审计 schema：预测内容、依据、时间戳、结果全部留痕
  • 防止事后诸葛：预测必须在结果揭晓前锁定
  • 区分运气与能力：看长期 Brier Score 均值，不是单次命中

边界声明

  • benchmark 数据为 2026-09-29 快照，后续版本会变化
  • 页面为静态研究页，无后端
