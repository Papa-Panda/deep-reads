Agent最佳实践之：Agent Context

一年多用 Claude Code、Codex 等编码 Agent 的实践提炼：把 Agent 的工作目录（agent context）与代码仓库分开——代码是输出，context 是记录与日志；用 git 管理，30 人部门共用一个 context、1500+ commits，交接工作就像交一个目录。值得他看的是它把「怎么用 Agent」变成可设计、可操作的协作协议，且附公开模板。

2026-11-06 · 作者：Weiyu Xie

原文链接：https://zhuanlan.zhihu.com/p/2101773507134805612

大纲

大纲

  • 核心主张：Agent Context 是独立对象
  • Agent 的启动目录与代码仓库分开
  • 代码是输出，Context 是记录/日志
  • 仓库只有 doc/src/scripts/tests，没有项目记录、设计意图、失败与实验报告
  • 工作流：Context 跨机器积累经验
  • 在工作机上启动 Agent，跨服务器/仓库改代码、跑实验
  • 结果写回 Context，经验不断累积
  • 文本惯性约束后续 Agent 的行为
  • 管理方式：用 git 管 Context
  • doc 放文档，ref 以链接/子模块挂其他仓库
  • 作者部门约 30 人自 4 月共用一个 Context，1500+ commits，每日提交
  • 交接工作 = 交一个目录，像网络协议一样对齐人与人
  • 落点：Agent Context 是基础层
  • 把「怎么用 Agent」变成可讨论、可设计、可操作的东西
  • 原则已开源：github.com/ErvinXie/meta-agent
