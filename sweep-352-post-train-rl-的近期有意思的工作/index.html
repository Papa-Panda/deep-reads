Post-train RL 的近期有意思的工作

孙元宝儿（echo-r1 团队）介绍两项后训练 RL 工作：Echo-N1 把 RL 从数学/代码拓展到共情对话（constitution + 生成式奖励模型，个性化宪法随用户画像动态生成）；MAPO 以 critic-free 的 REINFORCE + 组归一化融合逐轮与全局优势，解决多轮对话信用分配，Qwen2.5-7B 上 EMPA 分数 15.7→58.9。注：原回答链接已失效（404），内容通读自作者同名专栏版。

大纲

大纲（全文已通读；孙元宝儿，echo-r1 团队，编辑于 2026-03-10；180 赞 / 315 收藏）

  • 开场：团队近期两项工作
  • Echo-N1：共情对话的 RL
  • MAPO：长程多轮对话的策略优化
  • Echo-N1：RL 不只做数学/代码
  • 论点：RL 通用配方（偏好数据 → 奖励模型 → RL）与任务类型无关
  • 选共情对话这片「无人区」：没人做、参考点少
  • 规模：3 个月、近 10 人；SFT 数据合成、生成式 RM 三部曲、策略 RL、评测框架各可成篇
  • 核心：constitution + 生成式奖励模型
    • 借鉴 Claude 宪法 AI：宪法给模型人格一致的行为
    • 公理推定理：个性化宪法须随用户画像动态生成，不能由第三方代定
  • 奖励模型数据管线（图 3）
    • 筛选人工标注对话，挑需共情场景、排除不安全内容
    • LLM 作共情评判者：识别共情需求，分认知 / 情感 / 动机三类
    • Critique-Rewrite：按用户画像打 1–5 分，改写低分回答为金标版
    • 偏好对：高分 chosen，低分 reject
  • MAPO：多轮对话的信用分配
  • 现状问题：outcome reward + GRPO 解不了信用分配
  • 引入过程奖励 → GRPO 样本量指数爆炸；PPO 没这问题但难训
  • 思路：critic-free 只能靠组归一化；过程奖励就是 replay buffer 里的 (s,a,r)，REINFORCE 可直接优化
  • 混合优势：逐轮优势（同轮内归一化）与全局优势（整批归一化）的凸组合 A = α·A^t + β·A^b
  • 结果（表 1）：MAPO 全面胜过 Base 与 GRPO；小模型收益最大（Qwen2.5-7B EMPA 15.7→58.9）
  • 泛化：EmoBench / EQ-Bench 未训，纯外推仍有提升
  • 收尾：团队招人 / 合作；MAPO 代码整理中，将开源
