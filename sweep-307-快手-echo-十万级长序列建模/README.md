# 「快手」echo：十万级长序列建模

> 讲快手 ECHO 论文：用蒸馏教一个与候选无关的选择器，从 10 万条行为历史里挑出 Top-K 再精排，绕开检索式与压缩式长序列建模各自的短板；作者还给了独立批评和替代方案。值得他看的是它把长序列建模从“检索还是压缩”的二选一，还原为选择器、教师信号与 Top-K 边界监督的设计问题，且直指实验对照不公平。注：文中公式以图片呈现，未逐式核验。
