# 美国 9 月 CPI 数据公布，同比上涨 3.7%，高于市场预期的 3.6%，释放了哪些信号？

> 知乎热榜条目（约185万热度，28个回答）。美国9月CPI同比涨3.7%、核心CPI涨2.6%，双双高于预期，能源与黏性较强的服务价格是主要推手；这是10月27–28日美联储决议前最后一份通胀报告，市场把10月加息概率迅速推高到约五成。对正在判断利率会否长期维持高位、并据此给资产定价的他，这是本周最直接的宏观信号。注：据热榜数据摘要整理，头部回答全文未及逐条核验。
