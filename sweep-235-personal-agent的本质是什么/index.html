  • 知乎推荐流问题页（已登录态扫描 30 条，URL 经标题链接逐条核验）
  • 背景：2026 年秋 Personal Agent 集中发布（Meta Muse 9 月下载破 500 万、Manus Cue、OpenAI dot）
  • 本质之争：三代 AI 产品的分界
  • 第一代聊天机器人：以问答为中心，比知识与推理
  • 第二代数字员工／办公 Agent：以任务为中心，比能否把活干完
  • 第三代 Personal Agent：以人为中心——理解习惯、权限、日程与偏好，代表用户持续行动
  • 构成三要件（公开报道的共识拆法）
  • 一双手：能操作电脑与应用，从输出文字到真正执行
  • 一个身份：经授权以用户身份行动，凭证与审批边界随之而来
  • 一个持续运行的后台：关掉对话框任务不停，记忆与任务跟人走
  • 真瓶颈：两道授权
  • 用户授权只是第一道；平台是否允许 Agent 进入是第二道
  • 责任归属、审计与标准接口，可能比模型能力更决定这类产品能走多远
  • 为什么值得他看
  • 正对 Agent harness／runtime 主线：本质之问落在运行时、身份与记忆的系统设计上
