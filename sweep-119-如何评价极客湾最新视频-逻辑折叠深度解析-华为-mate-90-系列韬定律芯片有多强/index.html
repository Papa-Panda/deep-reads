大纲

大纲（据问题页与默认排序前 3 答整理；未登录仅可见前 3 答）

  • 事件：极客湾解析麒麟 9050 Pro（2026-10-02 发布）
  • 方法：切开芯片、电子显微镜观察内部结构 + Mate 90 Pro Max 实机测试
  • 问题页数据：224 个回答、182 万浏览；深度锚点是最高赞长答（1091 赞，答主「现实主义理想者」）
  • 逻辑折叠的机制（长答核心）
  • 两层 Die 之间为铜铜混合键合面，约八万个 TSV；穿孔余量使下层 Die 可用面积损失约 8%
  • 与常见 3D 堆叠的根本区别：不是 logic + Memory/缓存，而是把 CPU/GPU/NPU/ISP 同一 IP 内的不同逻辑模块分布到不同堆叠层
  • 布线证据：CPU Load/Store 模块布置在 L1/L2 缓存正上方，垂直缩短走线距离与功耗，反驳「两层叠加功耗爆炸」
  • 良率与成本账
  • 第一代较保守：单层 Die 面积比麒麟 9030 Pro 缩小 → 单 Die 良率升、发热与成本降
  • 代价：至少单芯片 ×2 加键合成本；长期靠单 Die 变小与外围共用，有望仅略高于单层大芯片
  • 性能坐标（长答转述极客湾实测）
  • CPU 单核能效介于骁龙 8 Gen2 与 8 Gen3 之间；多核能效几乎与天玑 9400 一致
  • GPU 中低频能效介于 8 Gen2 与 8 Gen3 之间，高频略优于 8 Gen2
  • 路线含义
  • 逻辑折叠被提出为绕开 EUV 几何微缩瓶颈的另一条路（长答以谷歌 Tensor G6 台积电 3nm 对比作论）
  • 平面 EDA/IP/工艺库是产业链惯性；被制裁倒逼重建工具链反而可能形成垂直整合优势
