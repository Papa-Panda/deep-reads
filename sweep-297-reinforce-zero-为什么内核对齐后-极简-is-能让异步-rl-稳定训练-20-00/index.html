REINFORCE Zero：为什么内核对齐后，极简 IS 能让异步 RL 稳定训练 20,000 步？

讲异步 LLM RL 为何不稳、又如何用内核对齐加最简单的 token 级重要性采样稳住 20,000 步：把对数比拆成权重滞后与内核失配两项，前者可由 IS 修正，后者必须靠训练-推理数值一致性消除。值得他看的是它把异步 RL 的不稳定从调参问题还原为数值执行问题，并给出可复用的对齐验证流程与泛化实验。注：该文标注 AI 辅助创作，发表时仅 4 赞，宜对照原文与 REINFORCE-Zero 项目核验。

大纲

大纲

  • 核心主张
  • 训练-推理数值一致（TII）后，只需最简、无截断的 token 级 IS
  • 无比率裁剪、无样本拒绝门控，仍可稳定跑 20,000 次策略更新
  • 关键拆分：对数比 = 两项偏差
  • 权重滞后：版本不同，沿优化轨迹渐变
  • 内核失配：同权重下执行路径不同，批组成、前向路径与浮点顺序都会引入波动
  • 同步权重消除不了内核失配
  • IS 尖峰机制
  • 概率误差经指数映射放大，诊断指标峰值/中位数在标准内核下远高于对齐内核
  • 未对齐时 rollout-learner KL 可暴涨数十倍
  • 均值层面：IS 为何优于 Score Centering
  • IS 可同时恢复零均值 score 与目标协方差
  • Score Centering 只去掉漂移项，仍留协方差差
  • 方差层面：均值正确不等于稳定
  • 低采样概率、高目标概率的动作会被 IS 放大
  • 失配增大时稳定学习率区间缩小，平方误差可能指数增长
  • 泛化实验
  • 长程推理：lag 2/8，均 20,000 步，KL 稳定
  • 高延迟工具调用：lag 64，奖励明显上升
  • 30B MoE 与 OSWorld 视觉操作：均有提升
  • 异步吞吐：同 16 卡下训练步耗时约降至 2.4 倍速
  • 工程落地
  • 对齐做成可复用 agent skill，11 项检查分三阶段
  • 建立参照、对齐验证、扩展优化；MoE 需路由回放
  • 代价：对齐执行在引用 workload 上增加约 6.8% 步耗时
