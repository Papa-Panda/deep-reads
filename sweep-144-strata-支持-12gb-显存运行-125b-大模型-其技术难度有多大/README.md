# Strata 支持 12GB 显存运行 125B 大模型，其技术难度有多大？

> 知乎热榜条目（17个回答，约7.2万浏览）。Strata 并不是把 125B 模型塞进 12GB 显存：目标模型极度稀疏、每 token 只激活一小部分，它把整台 PC 当分层存储用——GPU 放常驻部分与热专家，CPU/内存放完整专家池，SSD 放超大查找表，再加动态专家缓存与多 token 投机校验。前排回答既讲清机制，也给了实测（12GB 笔记本约 83 token/s、RTX 5090 约 207 token/s）与代价清单：只适用重度量化版本、单请求场景，且吃大内存与高速 SSD。对他看推理优化与本地部署成本结构很对口。已读默认排序前 3 答。
