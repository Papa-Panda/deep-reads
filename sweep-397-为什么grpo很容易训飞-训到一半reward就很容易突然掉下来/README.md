# 为什么GRPO很容易训飞，训到一半reward就很容易突然掉下来？

> 白露未晞me（2026-11-24）用三答案极简模型严格证明：GRPO 的组内相对优势 + 有限采样 + softmax 耦合，会让低于全局均值的平庸解拿到正优势、挤占最优解，G=8 时约 26% 的采样组算错方向；Clip 与 KL 在更新起点拦不住，偏差逐轮累积就是 reward 半路骤降的原因。注：原文链接为浏览器在知乎站内搜索核验后的有效地址（推荐流抓到的旧链接已失效）。
