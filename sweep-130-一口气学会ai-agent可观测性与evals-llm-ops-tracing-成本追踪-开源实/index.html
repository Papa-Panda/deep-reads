大纲

大纲（据 UP 简介与章节列表整理；该视频无字幕轨）

  • 问题：agent 刚做了什么、做得好不好，你其实不知道
  • 两个角色：可观测性 = 相机（记录跑了什么、花了多少）；eval = 裁判（判定够不够格发布）
  • 网关层：所有调用先过网关计量；treg 一个 API key 接入 3,800 个工具
  • 记忆层：Waku 可移植记忆，可从 Claude Code 直接调用
  • 实测一：一次研究任务调用 10 个工具、花费 29 美分、零错误；五段 agent loop 时间线逐步拆解
  • 发布门禁：单次运行跑 6 个 eval；总计 3,218 条确定性 eval 把关发布
  • 实测二：一次工具调用失败的运行，靠 trace 定位到问题环节
  • 落点：照着搭一套自己的可观测 + 评测链路
