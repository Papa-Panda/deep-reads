TREE(3) 有多大？

大纲

1. 引子：从葛立恒数到 TREE(3)

  • 葛立恒数已大到无法用常规记号写出；TREE(3) 比它还要大得多
  • 本视频耗时两年半打磨，是 UP 主“每天一个数学小知识”葛立恒数一期的续篇

2. TREE(n) 的游戏规则

  • 取一串有限树，每个节点标 1、2、3 三种标签之一
  • 序列规则：后面的树不能“包含”前面的树（不存在保持标签的同胚嵌入）
  • TREE(n) 就是满足规则的最长序列长度

3. 为什么序列必然终止：Kruskal 树定理

  • Kruskal 定理保证任何无限树序列中必有一棵可嵌入另一棵
  • 因此最长合法序列是有限的——TREE(3) 是一个确定的有限整数

4. 小情形对照：TREE(1) 与 TREE(2)

  • TREE(1) = 1，TREE(2) = 3，规模尚可手算
  • 标签从 2 增加到 3，长度从 3 跳到天文数字

5. 量级：与葛立恒数的对比

  • TREE(3) 远远大于葛立恒数，连高德纳箭头记号也难以企及
  • 直观解释：每多一个标签，嵌套的组合爆炸就上一个层级

6. 数学纵深：快增长层级与序数

  • TREE(3) 的增长速度对应快增长层级中极高的序数（约 Γ₀ 量级）
  • 它是“可证明存在、却无法具体写出”的大数的典型

7. 收束：有限与可把握的鸿沟

  • 有限 ≠ 可想象：数学能证明它存在，却给不出它的十进制写法
  • 第一性原理式的科普：从定义出发，一步步把“大”讲清楚
