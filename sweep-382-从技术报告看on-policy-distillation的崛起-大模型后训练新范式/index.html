从技术报告看On-Policy Distillation的崛起: 大模型后训练新范式

潜龙勿用对照 Qwen3、GLM-5、MiMo-V2、DeepSeek-V4 四份技术报告精讲 On-Policy Distillation：学生自己采样、教师逐 token 反馈，反向 KL 兼得 RL 的在策略性与蒸馏的稠密信号，AIME'24 上 1× 算力做到 74.4%（纯 RL 10× 算力才 67.6%）；并拆解 token-level vs 全词表 KL、OPD+ORM、多专家路由等分歧与 V4 的 TileLang 工程方案。直接对口后训练配方选型，值得慢读。

2026-11-22

原文链接：https://zhuanlan.zhihu.com/p/2031101471563962191

大纲

1. OPD 是什么：第三条路

  • 纯 RL（PPO/GRPO）：整条轨迹只有一个稀疏结果奖励，信号密度极低
  • 离线蒸馏：教师轨迹做静态 SFT，存在暴露偏差，学生一偏离教师轨迹监督就失真
  • OPD：学生按自身分布采样，教师逐 token 给 logprob 反馈；信号密度约为纯 RL 的 50–100 倍
  • 证据：同起点 AIME'24，离线蒸馏 60%（1× 算力）、纯 RL 67.6%（10×）、OPD 74.4%（1×）

2. 为什么用反向 KL

  • 反向 KL 是 mode-seeking：学生只学教师的一个高概率“模态”，不去平均所有解法
  • 推理任务适合：数学题有正确路径，不必模仿每种推导风格
  • 天然难 hack：KL 低即意味着在模仿好的教师行为，不像奖励函数可被钻空子

3. 工程实现：一行改动

  • 在 GRPO 框架上，把组归一化优势换成教师/学生 log-ratio（stop-gradient）
  • GLM-5、MiMo 均复用自家 RL 优化框架；GLM-5 组大小 32→1，batch 32→1024

4. 四大技术分歧

  • KL 粒度：token-level 是蒙特卡洛近似、省算力；全词表 KL 精确但显存爆炸（词表×序列×专家数）
  • 奖励信号：纯 KL（GLM-5、V4，能力恢复为主）vs OPD+ORM（MiMo，KL 给局部信号、ORM 给全局信号）
  • 教师选取：同架构 checkpoint（GLM-5，logit 天然对齐）vs 多领域专家路由（MiMo、V4，解耦设计可随时增减教师）
  • Pipeline 位置：Qwen3 独立轻量模型子流程、GLM-5 收尾修复、MiMo 核心第三阶段、V4 统一终点

5. 四家落地

  • Qwen3（2025-05）：先离线蒸馏打底、再 OPD；6 个轻量模型总成本仅为旗舰 4 阶段 RL 的 1/10
  • GLM-5：多阶段 RL 后的灾难性遗忘，用 OPD 做跨阶段蒸馏修复；HLE 50.4、SWE-bench Verified 77.8
  • MiMo-V2-Flash：MOPD + Rollout Routing Replay，学生多项指标超过最强教师；SWE-Bench Verified 73.4%
  • DeepSeek-V4：OPD 完全取代混合 RL；全词表 KL 靠教师权重调度、隐藏态缓存、TileLang 内核撑起

6. 未来方向

  • 全词表 KL 12–18 个月内成标配；OPD+PRM 从结果监督走向过程监督
  • 迭代师生共演化（类 AlphaZero 自博弈）；百万 token 长上下文的采样张力
  • 推理时蒸馏：在分叉 token 处实时查教师分布；范式总结：能力整合从参数空间移到 logit 空间
