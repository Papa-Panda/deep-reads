如何看待法国 AI 公司 Mistral 发布的最新模型 Mistral Large 4？

知乎热榜114万热度、仅24个回答，却罕见地数据密集：三位答主分别拆架构、算力与基准价格且数字互相印证。总参1.05T、每token激活49B的细粒度MoE路线、1.6B视觉编码器与长轨迹RL的组合指向一个为Agent任务优化的工具型模型；代价是专家权重全量驻留显存、只适合高并发服务。另两答补上欧洲算力约束（自建数据中心规模与成本）与Artificial Analysis基准和API定价对照。已读默认排序前3答。

大纲

大纲（据默认排序前 3 答整理）

  • 基本盘（三答一致）
  • 总参由 Large 3 的 675B 升至 1.05T（+约56%），每 token 激活仅 41B→49B（+约20%）：扩的是可路由专家空间，不是推理算力
  • 原生多模态、上下文 256k→1M、训练硬件约 3,800 块 Grace Blackwell
  • 架构答（38 赞，项目作者）
  • 稀疏激活不省显存与通信：全部专家权重须常驻多卡，适合高并发在线服务，不适合低批量私有部署
  • 1.6B 视觉编码器（上代 2.5B）把图像/PDF/图表变视觉 token，进 agent 循环做定位、放大、搜索与代码验证
  • 长轨迹 RL：混合验证器（单测/静态检查判代码、直查判计算、奖励模型或 LLM 裁判判其余）+ 异步 actor 与 trainer 处理陈旧与 off-policy 漂移 + 上下文压缩让单条 rollout 跨百万 token
  • 算力地缘答（92 赞，最高赞）
  • 欧洲缺算力：Mistral 规划的 1GW 数据中心造价高、投运慢，实际运行容量有限；在此约束下用约 3,800 卡从头训出 1T 基座本身是成就
  • 竞争判断偏悲观：非官方实测称其综合表现与成本不占优，热度可能有限
  • 基准与价格答（67 赞）
  • AA 总分接近 DeepSeek-V4.1-Flash；分项呈典型工具型分布：AutomationBench、Terminal-Bench 等 agent 任务排名靠前，HLE、CritPt、Omniscience 等知识与物理推理明显偏弱
  • API 定价与 GLM-5.3 同档，明显高于 Flash 类模型
  • 一句话：强在可验证反馈的 agent 活，弱在开放知识与科研推理
