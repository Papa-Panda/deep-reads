大纲

大纲（据浏览器通读该问题下高赞回答整理，概括转述）

  • 断言：三年内扩散模型全面替代大语言模型？
  • 回答共识：全面替代难断言，共存与分工更可信
  • 一、扩散 LLM 的生成方式
  • 多位置并行预测掩码，而非逐 token 自回归
  • 代表模型：Dream-7B、LLaDA、DiffusionGemma、Mercury、Clover-35B-A3B
  • 二、支持替代的论据
  • 并行解码带来低延迟
  • 模板化、结构化与 Agent 工具调用类任务上表现强
  • 稠密模型上有 3.7–5 倍提速的说法
  • 三、反方
  • 训练更难，去噪步数多
  • 等算力下学习效率不如自回归
  • 大批量下输给自回归，更可能作为 speculative decoding 的草稿模型
  • 四、给 AI Infra 的核心变化
  • 速度声明主要是单用户延迟，不是云端吞吐：自回归解码受显存带宽约束、批量几乎免费；扩散去噪是整序列或块的算力约束，并发上来吞吐曲线先 flatten
  • KV Cache 与 PagedAttention 假设失效：纯双向扩散下标准 KV Cache 不成立，Fast-dLLM 用块级近似 KV Cache
  • PD 分离弱化：每步去噪都像 prefill
  • 块大小成为新调度参数：空闲时大块保延迟，高峰时小块保吞吐
  • 延迟更难预测：置信度提前结束使步数不定；按 token 计价变不公平
  • 五、落点
  • 端侧单用户场景可能先落地
  • 推理芯片重心或从 HBM 带宽转向算力密度
  • 框架可能把自回归看作块大小为 1 的特例
