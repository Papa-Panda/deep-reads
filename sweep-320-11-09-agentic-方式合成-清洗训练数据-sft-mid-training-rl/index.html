【11-09】agentic 方式合成 / 清洗训练数据 (SFT・mid-training・RL)

Lei Tian 的每周论文精读：8 篇 11 月新论文，讲如何用 agentic 方式合成、筛选与清洗训练数据，服务 SFT、mid-training 与 RL——主线是把真实交互中的信息变成下一轮可验证的训练信号。值得他看的是它正撞后训练数据主线：Harness-S 用“兄弟 harness”解决 GRPO 有效组不足、Agent-R² 用真实附件与交付级 rubric 做办公 agent 数据、ToolSpace 以可执行工具依赖为合成单元、Axion 拆分“变难”与“真需工具”两条数据流；作者还逐篇标注了实验口径上的坑（均值 vs 最佳值、dev/test 混淆），可直接当本周数据工作的阅读地图。全文已通读。

大纲

大纲（全文已通读）

  • 总纲：本周主线——把真实交互变成可验证的训练信号
  • 范围：8 篇 arXiv 首发 2026-11-02–11-09，方向 agentic 合成/筛选/清洗训练数据，服务 SFT、mid-training、RL
  • 作者推荐精读：Harness-S、Agent-R²、VidUEU-Agent（有效训练组从哪来、任务分与完成率为何分叉、数据分布反馈如何不混淆 dev/test）
    1. Harness-S：兄弟 harness 救活 GRPO 有效组
  • 痛点：原 harness 全组失败时 GRPO 组内无奖励方差
  • 方法：edit agent 按失败原因生成兄弟 harness；仅当整组失败才路由多兄弟重跑，救援组替换失败组；按行为画像路由并随策略更新重校准
  • 实验：Qwen3.5-4B AppWorld Avg@3 48.98%→56.87%；有效组比 64.69%→79.38%；代价 +18.44% rollouts
    1. Agent-R²：真实附件 + 交付级 rubric 的办公 agent 数据
  • 痛点：办公 agent 常不读附件、不验算就交文件
  • 方法：O*NET 活动播种、真实附件检索验证、沙箱校验、专家执行 + verifier 核对交付物；SFT 后按交付 rubric 做 RL
  • 实验：GDPval Pass@1 32.4%→45.3%→51.0%；SFT 后步骤暴涨但完成率跌，RL 后回升——探索与可靠完成要分开量
    1. ToolSpace：以可执行工具依赖为合成单元
  • 痛点：先造库再让 LLM 编工具，调用关系脱离真实执行
  • 方法：从真实 MCP 调用挖掘数据/状态/重试依赖成加权工具图；随机游走 + 状态检查回滚；三重验证 V_state/V_trace/V_out
  • 实验：35B 七基准均值 23.0→41.0→43.2；真实执行边胜 LLM 判断边（45.8 vs 37.8）
    1. Axion 1.0：把“变难”与“真需工具”拆成两条数据流
  • 方法：Stage 1 针对基座已会解的题做组合/参数化/分情形变换再验算；Stage 2 在真实结构化数据上做确定性计算、屏蔽建库、防闭卷可答；RL 用前缀进度奖励
  • 实验：35B HLE-130 47.7%→70.0%；但 BioMysteryBench SFT-I 先跌后涨，FrontierScience RL 后微跌——最后阶段并非处处有效
    1. CUA-Master：从外部教程 import 工作流 + 失败快照回滚
  • 方法：教程视频触发点重建轨迹；任务抽象为原语组合；失败定位最早偏离点、恢复快照、只保留成功且更高效分支；外层循环按能力缺口再采集
  • 实验：长任务同重试预算下全重启成功率 14.6% vs 快照回滚 49.8%
    1. WebHarbor：把真实网站“靠岸”成可离线复现的环境
  • 方法：按目标任务定范围重建前后端 + SQLite 状态；逐步执行修补缺失页/状态转移；人工评审视觉、功能、任务有效性
  • 实验：离线重建环境迁移到真实网站 WebVoyager 81.2%；但 WebArena 迁移有限（28.8%），环境建设成本高（57 人约 5 个月）
    1. VidUEU-Agent：视频数据的证据组织 + 分布反馈外循环
  • 方法：三级摘要 + 镜头过滤；按内容规划 OCR/ASR/检测/光流工具；样本必须引用所用信号 ID；每轮 30K 数据、按评估调分布后扩到 100K
  • 实验：InternVL3-8B MMT-Bench 0.546→0.596；注意反馈用的是测试集聚合分，held-out VSI-Bench 才是迁移的可靠读数
    1. PyRUA-DataFarm：造数据与批数据分离的机器人数据
  • 方法：编码 agent 重建场景写专家控制器；独立角色先冻结成功判定；视频模型只按真实参考图渲染外观；每集机器检查 + 独立审片
  • 实验：5 个双臂任务原场景 93/100 胜真人遥操 84/100；未见桌布/灯光下 87 vs 46；单集摊薄约 $1.06
  • 作者总结与阅读口径提醒
  • 通用教训：互补 harness 是探索工具；SFT 跌完成率、RL 恢复的模式比“小模型胜大模型”更重要；合成单元应是可执行依赖；造数据与批数据要分离
  • 口径坑：区分 Pass@3 与 Avg@3、均值与最佳值、dev 指导与 held-out 泛化、训练成本与全流程成本
