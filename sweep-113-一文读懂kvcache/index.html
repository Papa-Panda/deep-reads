一文读懂KVCache

2024 年经典硬核长文（1861 赞、3629 收藏）：从 GPT2 实测讲起——新增 token 时历史 embedding 变化仅 1e-5，这是 KV Cache 的实验依据；对比三种缓存方案的存储与计算开销，给出 PagedAttention 的工程实现，并点出成立条件是因果性（decoder-only 才可用）。评论区有作者亲承的算术勘误和 KV Cache 本质是变长 RNN state 的点睛，推理优化基本功，配 vLLM 源码看最对味。

大纲

大纲

  • 动机：为什么需要 KV Cache
  • 推理一步的流程：n 个 token → embedding → L 层 transformer → lm_head 预测下一个 token
  • GPT2 实测：新增 token 时历史 token 各层 embedding 最大变化约 1e-5，历史计算可复用
  • 小插曲：神经网络计算的确定性
  • 微小差异来源：浮点加法无结合律、GPU 并行归约顺序不同
  • 原则上确定，实际带有舍入与并行噪声
  • 原理与设计：三种缓存方案对比
  • x cache、k+v cache、s cache 的存储与 FLOPS 对比
  • 结论：k+v cache 是实用选择；s cache 只在缓存复用极高时划算
  • 存储与实现：PagedAttention
  • 动态倍增式 buffer 在 GPU 上反复 alloc/free 开销大
  • vLLM 的 PagedAttention：预分配一大块显存（如 4GB），按 token 切成小块管理
  • 成立条件：因果性
  • 每个 token 的输出只依赖自身及之前的输入（causal mask）；BERT 类 encoder 不满足
  • 反例：ReRoPE 等位置编码会移动历史 token，条件被破坏
  • 评论区精华与勘误
  • 点睛评论：KV Cache 的本质是 variable size 的 RNN state
  • 存储表漏乘头数因子、FLOPS 算式有误，作者已在评论区承认
