Trust Region in LLM RL: TRPO, DPPO and AReaL 数学原理

从性能差引理出发，推导 LLM 有限时域下的信任域界，并对照 TRPO、PPO、DPPO 与 AReaL 在信任域中心、距离定义与约束方式上的差别：为什么单 token 比率是失真的代理、完整分布散度与异步解耦各解决什么问题。值得他看的是它直击后训练 RL 的核心数学——长 CoT 下耦合误差如何累积、异步训练中新鲜度与漂移须联合监控。注：该文为理论综合学习笔记（标注 AI 辅助创作，发表时仅 6 赞 9 收藏），无新实验，宜对照引用的 TRPO/DPPO/AReaL 原文核验。

大纲

大纲

  • 问题定义
  • 性能差引理：新旧策略回报差的精确表达
  • 伸缩求和（telescoping）推导：TD 残差如何消去中间项
  • 从真实目标到代理目标
  • 固定旧策略的状态访问分布，得到局部代理
  • 重要性采样只修正动作分布，不修正状态分布漂移
  • 信任域界：真实回报 ≥ 代理 − 常数 × 最大 TV 散度平方
  • LLM 有限时域形式
  • 状态 = 提示 + 已生成前缀，终点为 RLVR 奖励
  • 序列比率拆成 token-wise 一阶代理 + 高阶耦合误差
  • 有限时域界随 horizon 二次增长：长 CoT 下小步也会累积
  • TRPO：显式约束平均 KL
  • 在采样平均前向 KL 约束下最大化 token-wise 优势代理
  • 自然梯度（Fisher 几何）+ 线搜索近似求解
  • 局限：平均 KL 会掩盖少数前缀的大漂移
  • PPO：从显式约束到裁剪代理
  • 单 token 比率裁剪只是 TV 散度的一样本代理
  • 结构性偏差：低概率 token 过约束、高概率质量移动欠约束
  • DPPO：用完整分布散度决定是否停止更新
  • 方向感知掩码：仅在朝优势方向且散度越阈时屏蔽
  • Binary / Top-K 聚合：数据加工不等式保证的散度下界
  • 掩码是违规检测器，不是投影或约束求解器
  • AReaL：异步训练中的解耦 PPO
  • 三种策略：behavior / proximal / current
  • 解耦比率：行为修正比 × 信任域比，只裁剪后者
  • 陈旧度约束：最大版本滞后，混合版本轨迹
  • 局限：近端锚不直接界定 rollout 到当前的总漂移
  • 统一比较与实现检查清单
  • 三问区分三法：中心是谁、距离怎么定义、约束怎么执行
  • 异步 LLM RL 须联合监控新鲜度、散度与陈旧度
