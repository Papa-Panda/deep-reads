# Agentic RL 训练：它不是单一 RL 算法，而是一整套环境建模、学习信号、异步数据流、策略优化和基础设施的协同系统

> 长文框架综述：Agentic RL 不是换个 PPO/GRPO 变体，而是长时程、调工具、部分可观测、异步执行的系统性策略学习；提出三个不变量（可探索策略空间不坍缩、学习信号不退化、分布偏移可控）与八个方面，贯通 Kimi、MiniMax、GLM 的技术报告与 DAPO、TITO、CISPO 等机制。值得他看的是它把 Agent RL 从算法选择还原为环境、信号、分布与系统的闭环，正对后训练主线。
