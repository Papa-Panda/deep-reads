  • 14 个 AI 各自写出一个坦克对战程序，程序之间互相对战，模型不直接操控
  • 共打 14,400 局，胜负标准是先拆掉对方老家；局数足够大，能摊掉单局运气
  • 标尺：陪练 bot
  • 出题方用 Claude 花数小时打磨出一个最强陪练 bot，作为统一参照
  • 简介列明参赛测试用到多个模型 API（Muse、Gemini 等，由赞助者协助以原价 API 测试）
  • 为什么值得看
  • 这是 coding agent 能力的擂台式评测：要交出完整、可运行、能长期对战的策略程序，而不是答一道题
  • 大规模对局＋开源实现，结果可复现、可自己上手挑战，是比跑分榜更立体的能力样本
  • 开源与复现
  • 全系列开源（GitHub: chen-006/meow-ai-arena），可下载陪练与赛制自己复现实验
  • 局限（先说清）
  • 形式偏娱乐向；单一游戏规则下的排名不能外推为通用编程能力
  • 真正的看点在评测设计本身：任务定义、标尺构造与对局规模，而不是名次结论
