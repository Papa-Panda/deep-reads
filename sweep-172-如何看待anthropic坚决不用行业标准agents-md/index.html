如何看待Anthropic坚决不用行业标准AGENTS.md？

知乎热榜条目（约55万热度，19个回答，关注78，浏览约13.9万）。AGENTS.md 已被6万多开源项目采用，Claude Code 却长期只认自家 CLAUDE.md。头部回答（260/141/105赞）三条线：变通派说在 CLAUDE.md 里写一行转读即可；过程派扒出时间线——需求2025年8月就提出，直到大客户施压后才在2026-09-18上线有限支持（无 CLAUDE.md 时才回退、需开关、云渠道不可用），本质是品牌与锁定；标准派说 Skills 靠通用性扩散，专属文件名必然催生中立标准。正对他的 agent harness 主线：规则文件之争就是生态入口之争。注：本轮知乎在 worker 侧为登出状态，个性化流不可读，故知乎槽位用热榜兜底。

大纲（据默认排序前 3 答整理）

  • 事件本体
  • AGENTS.md 已成行业标准（6 万+开源项目采用），Claude Code 长期只认自家 CLAUDE.md
  • 问题页 19 个回答、78 关注、浏览约 13.9 万，热榜约 55 万热度
  • 变通派（约 260 赞，最高）
  • 不必维护两份规则：在 CLAUDE.md 里写一行，让工具转去读 AGENTS.md
  • 过程派（约 141 赞）
  • 需求早在 2025 年 8 月就提出，官方长期以技术障碍推托
  • 转折来自大企业客户施压（Shopify 层面提出可能全公司禁用）
  • 2026-09-18 上线的支持仍有限：仅在无 CLAUDE.md 时回退、需 /config 开关、Bedrock/Vertex/Foundry 不可用
  • 论点：保留专属文件名是每个仓库里的品牌与锁定，驱动决策的是收入而非开放
  • 标准派（约 105 赞）
  • Skills 能扩散靠的是通用性；厂商专属命名必然催生中立的 AGENTS.md
  • 结论：这一步 Anthropic 走错了，直接兼容即可
  • 落点
  • 规则文件是 agent harness 的入口层，标准之争即生态话语权之争
