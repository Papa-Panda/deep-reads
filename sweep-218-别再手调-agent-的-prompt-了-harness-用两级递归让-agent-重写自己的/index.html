别再手调 Agent 的 Prompt 了：Harness² 用两级递归让 Agent 重写自己的外壳

知乎推荐流条目（Arthur，2026-10-20 发布；读时 4 赞同、14 收藏、0 评论。已据完整原文更正——先前版本误记了出处与基准名）。文章解读论文 Harness²（arXiv:2610.14224）：把 Agent 看作模型加外壳，权重冻结时增益来自递归改写外壳。外壳被拆成 8 个可编辑文件（系统提示、护栏、长期记忆、工具指引、子代理、技能、脚本、插件），可 diff、可审计、可回滚，并有校验器把关。递归分两级：任务级用对比式三步（提出候选、探针试跑、择优合成）处理没有标准答案的开放任务，拿参考执行的行为差异当信号，连「不改」都是合法输出；经验级则在任务后复盘，把生效的外壳与经验条目存进库，下个任务继承经验而非继承过拟合的外壳。实验在三个职业基准上一步即全面超过基线，最佳配置 +11.5 分，且两个配置都落在算力-表现的帕累托前沿上；消融显示库、双候选拆分与合成三部件都在起作用。作者自评的短板也实在：只有相对成本没有绝对美元账、裁判决定分数、单次运行证据弱、经验库尚无合并与剪枝。

大纲（据完整原文通读整理，2026-10-22 更正版）

  • 条目信息
  • 知乎推荐流专栏，作者 Arthur，发布于 2026-10-20 07:52（江苏）；读时 4 赞同、14 收藏、0 评论
  • 解读对象：论文 Harness²（arXiv:2610.14224）
  • 核心判断：Agent = 模型 + 外壳
  • 权重冻结时，增益只能来自外壳；手调 prompt 是最低效的改法
  • 外壳应是可 diff、可审计、可回滚的文件树，而非散落的提示词
  • 外壳拆成 8 个可编辑文件
  • 上下文类：系统提示、护栏、长期记忆、工具指引
  • 编排与扩展类：子代理、技能、脚本、插件
  • 每次改动过校验器： always-on 字符上限、技能触发句、脚本存在且可编译、自动触发插入等
  • 任务级递归：没有标准答案时比行为差异
  • 先跑一次参考执行，只观察行为、不打分
  • 双路提案：一条找跨域通病（规划、工具、上下文、委派），一条找领域特有问题
  • 探针：两路在同一任务同一模型上试跑，只记录与参考执行的行为对比
  • 合成：合并有证据支持的改动、解冲突、只采一路、或判定不改——不改是合法输出
  • 扩展两个方向：并行加宽（多组候选加盲选，评选者只看匿名交付物）与顺序加深（检查点携带累积证据）
  • 经验级递归：把怎么改也存成资产
  • 任务后复盘全程记录，把生效外壳与经验条目（情境、教训、证据，判定含帮助/伤害/无观察效应/混杂）存进库
  • 混杂时如实标混杂，不硬做归因
  • 新任务继承经验，不继承上个任务过拟合的外壳
  • 实验（论文报告）
  • 执行模型为 Gemini 3.5 Flash 与 GLM-5，初始外壳 OpenCode 与 Codex，编辑与评选由 Claude Opus 4.8 担任
  • 基准：WorkBuddy-Bench 100 题、JobBench、LAB 法律 100 题
  • 一步（k=1）即在 4 种配置乘 3 个基准上全面超过基线，最佳为 GLM-5 加 OpenCode 在 WorkBuddy 上 64.2 到 75.7；k=5 再多涨数分，两个配置都在算力-表现帕累托前沿上
  • 同模型自编辑也成立；消融去掉库、去掉双路拆分、去掉合成都会掉分，技能与脚本约占改动一半
  • 失败分析与作者自评
  • 九次负收益归为三类：盲选评选者选错、候选共享错误前提、执行与裁判噪声
  • 具体案例显示改一行文件（如护栏加对账脚本、技能修正粒度口径）可救回数十分
  • 短板：只有相对成本无绝对美元账、裁判定义分数、单次运行证据弱、弱模型涨得多可能含天花板效应、经验库会老化且尚无合并剪枝
