# 如何评价上海交大 IPADS开源的 Skill编译器 SkVM？

> 知乎回答（作者 tomsheep）评析上交 IPADS 开源的 SkVM：把 Skill 从可移植的提示词文本，重新理解为需要在不同模型与 Agent 框架上适配的程序，用编译思路提升其可靠性。值得他看的是这条把 Agent infra 的关键痛点——同一 Skill 换模型、换框架、换环境就失灵——拆成可度量、可补偿、可并行化的工程问题；文中实验数字为回答所称，未独立核验。
