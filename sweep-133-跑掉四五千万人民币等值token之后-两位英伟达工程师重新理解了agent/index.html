跑掉四五千万人民币等值Token之后，两位英伟达工程师重新理解了Agent

涌现Lab 对谈两位英伟达工程师：相关工作烧掉约四五千万元等值 token 之后的方法论沉淀。核心是规格驱动的 RLCR 循环（写规格而非写代码、构建者加审查者双模型），同一套循环搬到 KDA 内核优化，六周赛期做到全赛道前三、单内核收敛从 24 小时压到 6–8 小时；并断言多智能体照搬公司组织是过家家、新模型一来要先拆旧 harness。对他的 agent 工程与 harness 观察是难得的一线样本。字幕稿经核验吻合，前 33 分钟据稿整理、后段据简介时间线。

大纲

大纲（前约 33 分钟据字幕稿整理，字幕经核验与视频吻合；后段据 UP 简介时间线）

  • 背景：两位英伟达工程师朱力耕、刘思皓，相关工作合计消耗约 4,000–5,000 万元人民币等值 token
  • Humanize 起源：由刘思皓 PhD 项目 Loom（多核异构加速器框架，约 60 万行代码、近一人完成）演化；工作方式从写代码转为写 1–2k 行自然语言规格，由 agent 生成上万行代码
  • GAAC 的教训：把 GitHub 的 issues/PR 当 agent 上下文，处理一百多个 issue 后退化；诊断是照搬公司组织分工行不通——agent 之间传递上下文是有损压缩，多智能体照搬人类分工被称作过家家
  • RLCR 循环：计划 → Claude 构建 → Codex/GPT 审查是否真的按规格实现（Gemini 与小模型委员会当审查者都试过，效果弱）；Humanize v1 可连续运行 10–20 小时完整实现规格；迭代哲学是小步累积，1–2% 的改进乘以 100 轮，约 5 轮无进展就停
  • KDA 内核优化：同一循环加两件套——Kernel Wiki（近期热门仓库已合并 PR 的经验汇总）与细粒度 profiler（从 NCU 出发，暴露 bank conflict、SM 利用率等，而不只是最终时延）；六周赛期内核心开发约一周，成绩全赛道前三；单个内核收敛从 24 小时以上压到通常 6–8 小时
  • Agent 原生 DSL：CUDA/Triton 是为人设计的；一位嘉宾称自己的 Codex 两个月写出约 800 万与 1,600 万行代码；他们转向 Cake、TileX 等 agent 原生语言
  • 接力流：RLCR 缺多样性，改用两个强模型接力——一个跑满预算后被强制总结并停下，交棒给另一个，再交回；用模型多样性逃出单个模型到不了的局部最优
  • 后段主题（据简介时间线）：token 如何变成真实生产力；无数学背景的跨领域团队挑战数学榜；批量生成算子之后软件工程怎么变；新模型一来先拆掉旧 harness；模型学会的 skill 与工程师的转向；代码不是护城河，时间才是；RSI 的阿拉丁神灯：用 token 换效率、用效率换更多 token
