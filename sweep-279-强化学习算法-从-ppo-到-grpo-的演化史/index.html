强化学习算法：从 PPO 到 GRPO 的演化史

从两条轴讲清 PPO 到 GRPO 的演化：优势估计怎么算、策略能走多远。核心论点是 GRPO 只改了优势估计（组内基线替代 Critic），没改 PPO 的裁剪目标；随后用 Dr. GRPO、DAPO、GSPO 三个 2025 补丁讲清组内归一化的长度/难度偏差、熵坍塌与 token 级比率方差问题。值得他看的是它把后训练 RL 配方的关键取舍拆成了可对照的机制与公式，并明确划了适用边界：这套路子在 LLM 上成立，在游戏/控制任务里不成立。注：知乎直取 403，内容据浏览器通读整理，概括转述。

大纲

大纲（据浏览器通读整理，概括转述）

  • 总论：两条轴看演化
  • 估计轴：优势 Ψ 怎么算
  • 目标轴：策略一步能走多远
  • 一句话论点：GRPO = PPO 裁剪目标 − Critic + 组内基线，只改估计轴
  • 一、PPO 在通用 RL 里为什么是对的
  • 裁剪目标 + GAE 优势，概率比裁剪使一批数据可安全复用多轮
  • 游戏/控制任务里 Critic 便宜、奖励稠密、回合可廉价重置，方差收益值得成本
  • 二、PPO 搬进大模型后成本结构翻转
  • Critic 须与策略同尺寸，7B 量级下四模型并存使显存翻倍
  • 奖励只在末 token，Critic 要从稀疏信号反推每个 token 的价值
  • 四模型 + 一组超参，工程与调参成本高企
  • 三、岔路 DPO：绕过整个 RL 循环
  • 与 PPO 解同一 KL 正则目标，借最优策略闭式解把奖励表成策略比，代入偏好模型后配分函数消掉
  • 代价：离线，适合风格/安全/有用性对齐，不适合靠探索提升推理
  • DPO 不是 GRPO 的前身：一个改解法，一个改优势估计
  • 四、GRPO（2024.02，DeepSeekMath）
  • 每 prompt 采 G 条回复，组内归一化优势，同一回复各 token 共享优势
  • KL 从奖励内逐 token 惩罚移到损失项，用无偏 k3 估计量
  • G 是新关键超参：太小则均值/方差噪声大，太大则采样成本线性涨
  • 五、2025 的四个补丁
  • Dr. GRPO：去掉长度与难度归一化，纠正短答案占优、全对/全错组被放大的偏差
  • DAPO：解耦裁剪上下限防熵坍塌、动态采样丢零梯度 prompt、token 级损失、超长奖励塑形；去 KL 是有争议的取舍
  • GSPO：token 级比率方差过大（尤其 MoE 路由变化时），改用序列级几何平均比率裁剪
  • 小结：Dr. GRPO 在估计轴，DAPO 横跨两轴，GSPO 回到目标轴
  • 六、横向对比与适用边界
  • 模型数一路下降，变化重心从“怎么估优势”移到“在哪一层加约束”
  • LLM 轨迹有限、同一 prompt 的 G 条解天然可比，蒙特卡洛回报可直接用；游戏回合发散且无限时域，离不开 Critic
