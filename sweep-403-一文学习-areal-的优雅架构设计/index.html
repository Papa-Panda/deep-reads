大纲

1. 为什么读 AReaL

  • Infra 社区公认代码优雅；异步训练设计（吴翼主导）被视为业界领先
  • 入口：examples/math/gsm8k_grpo.py，全链路跟踪

2. 初始化：三引擎 + 权重更新通道

  • 训练引擎 FSDPPPOActor、推理引擎 RemoteSGLangEngine、可选 reference 引擎
  • actor → rollout 的 weight_update_meta 通道

3. Rollout：Workflow 是核心抽象

  • RolloutWorkflow.arun_episode()：组 prompt、并发采样、算 reward、组 trajectory
  • RLVRWorkflow / MultiTurnWorkflow 各自实现

4. WorkflowExecutor：生产者-消费者解耦

  • 主线程提交、生产者线程按容量投递、消费者线程取结果
  • AsyncTaskRunner 跑 async 事件循环处理 agenerate

5. StalenessManager：管住样本新鲜度

  • 并发上限 + staleness 上限（max_staleness 等），样本最多落后限定个权重版本

6. DistRolloutCoordinator：FFD 负载均衡

  • all-gather 后按 token 数 FFD 重打包、去 padding；head-worker + dist.barrier

7. 训练与权重更新

  • 按 token 数切 micro-batch（max_tokens_per_mb）防 OOM；前向 / log-prob / KL / advantage / 反向 / optimizer.step()
  • NCCL 广播或落盘两种权重更新；rollout 侧 HTTP 同步远程 SGLang

8. Ray Placement Group：资源 DSL

  • "sglang[rollout]:d2+fsdp[actor]:d4+fsdp[critic]:d2"，+ 分离、| 共置；节点级 bundle 防碎片
