如何评价字节 Seed 团队发现 DeepSeek 性能漂移？

知乎热榜约291万热度、18个回答。字节 Seed 论文《Periodic Weak Spots》指出 DeepSeek V4 系列的压缩稀疏注意力会让长上下文检索精度随 token 位置周期性起伏：同一条事实只因前缀多了几个 token、落进压缩窗口的不同槽位，命中率可差出数十个百分点，而平均分几乎看不出来。前排三答从机制、消融因果到线上复现（系统提示多一个空格就可能翻车）层层坐实，并给出 padding 扫描、按相位报告精度等可落地的评测与部署对策。已读默认排序前3答。

大纲

大纲（据默认排序前 3 答整理）

  • 事件本体
  • 字节 Seed 论文《Periodic Weak Spots》：DeepSeek V4 系列使用压缩稀疏注意力，长上下文下出现性能漂移；问题页约 14.6 万浏览、195 关注
  • 机制：相位敏感而非渐进衰减
  • CSA 以窗口 8、步幅 4 重叠压缩 token 块，KV 量降至约四分之一后由 Indexer 挑选；HCA 则把 128 个 token 合并为一，两者在层间交替
  • 事实落在压缩窗口哪个槽位，决定它在压缩表示中的权重与可检索性；相位（位置对步幅取模）在全注意力里无意义，在块压缩里却成了因果变量
  • 证据链
  • 128K 针尖测试（1.6 万条记录、按相位分组，其余条件对齐）：V4 基础与后训练模型呈周期 4 振荡，最好与最差组差 15–40 个百分点，相隔整周期仅差 1–2 点
  • 代码实验：只逐 token 拉长前置文档字符串，V4 补全偏好以周期 4 翻转；无块压缩的对照模型基本无此现象
  • 小模型从零复现：压缩版平均精度与全注意力接近，但最差相位可低约 50 个百分点——是稳定性问题，不是平均能力问题
  • 因果定位：消融特定 KV 头只伤少数相位；把门控参数循环移一位，弱点相位随之移一位；窗口边界相位恒弱
  • 为何训练不自愈
  • 理论上单头专攻一个槽位即最优且梯度稳定，训练没有动力让不同头覆盖不同槽位；后训练能缩小差距但消不掉周期
  • 缓解与版本差异
  • V4.1 差距明显变小（最差组仍达约 89%），多答归因于压缩率降低与结构调整，但步幅 2 仍留下周期 2
  • 部署侧短策：把上下文长度当受控变量，高一致性任务做 padding 扫描、多前缀长度投票；评测侧应按相位报告精度而非只报均值
  • 边界
  • 收益真实存在：压缩带来的显存与速度优势不假；风险可能适用于一切固定步幅块压缩 KV 方案
