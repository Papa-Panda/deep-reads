RL loss 是近似的一阶 Taylor 展开

第一性原理重推 LLM 后训练 RL loss：想优化序列级 reward 却用 token 级加权似然训练，重要性比率≈一阶 Taylor 展开；统一解释高 off-policyness 下 RL 崩溃（方差爆炸），重释 Qwen 团队 RL 稳定化推导，论证 GSPO 与 TRPO 在自然梯度下近乎一致，并从该视角重看 DPPO。RL 训练理论+数学第一性原理，配他的 Agent RL 配方工作读最对味。

大纲

大纲

  • 动机：想优化序列级 reward，实际却用 token 级加权似然训练——它为什么能 work、什么时候会崩
  • 核心重推导：重要性比率 ≈ 一阶 Taylor 展开
  • 序列级目标 vs token 级 surrogate 的形式差
  • 把重要性比率做展开，RL loss 的一阶近似本质
  • 高 off-policyness 下 RL 崩溃的统一解释：方差爆炸
  • 重释 Qwen 团队的 RL 稳定化推导：从展开视角看那些 trick 为什么有效
  • GSPO vs TRPO：自然梯度下两者近乎一致的论证
  • 从该视角重看 DPPO
  • 边界：近似成立的假设（比率接近 1、on-policy 程度）
