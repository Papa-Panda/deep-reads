盘点近期loop架构的工业级实现及带来的scaling law

盘点商汤 SenseNova-Loop-9B 与英伟达 Dory1.0-4B 两个 loop 架构的工业实现：只 loop 中间层、mHC 与 nGPT 两种跨 loop 控制、TBPTL 与难度感知 RLVR 课程、自投机解码与 KV 缓存优化，以及“隐式计算替代显式 token、推理深度不等于知识容量、k=2 是甜点”的 scaling law。直接对口后训练与 Agent 任务的架构选型，值得慢读。

大纲

1. 为什么 loop 架构现在才工业落地

  • 学术上不新：Universal Transformer → Huginn → Ouro，权重复用换计算深度
  • 三堵墙：跨 loop 数值稳定与表征退化、训练梯度/显存成本、推理 KV 增长与解码延迟
  • 两个工业证明：商汤 SenseNova-Loop-9B（开源）、英伟达 Dory1.0-4B

2. 拓扑共识：只 loop 中间层

  • 输入-循环-输出三段式，绝不全层循环
  • SenseNova-Loop-9B：32 层物理层，首尾各 4 层跑一次，中间 24 层循环 2 次，等效 56 层深度，算力约当 14.6B 模型；3:1 混合注意力
  • Dory1.0-4B：36 层，中间 20 层动态循环 k=1~4，等效 72~192 子层
  • 只 loop 中间的原因：底层升维/顶层解码的表征角色不同；混合注意力周期对齐；首尾独立层吸收权重复用的梯度冲击

3. 跨 loop 控制机制：两条路线

  • 标准 PreNorm 残差会随深度范数膨胀、早期输出被稀释，权重复用下还会漂移或坍缩
  • SenseNova：双流 mHC，20 次 Sinkhorn 迭代把残差混合矩阵约束在双随机流形上，范数有界、状态分离
  • Dory：nGPT 超球面约束（逐 token L2 归一化）+ 输入重注入 h_t = F_θ(𝒩(h_{t−1} + x))，锚定原始表征并给出梯度捷径
  • 循环次数策略：SenseNova 静态 k=2；Dory 预训练混 k，推理按需选 k

4. 训练：loop 深度成为第四维

  • TBPTL：前 k−1 轮只前向不建图，仅最后一轮加输入/输出块保留计算图；6T token 预训练（前 4.5T 原生 NVFP4）
  • 难度感知 RLVR 课程：按平均通过率给 prompt 定难度，难样本配更深循环；Terminal-Bench v2.1 准确率 14.0% → 21.4%

5. 推理：loop=1 是原生草稿模型

  • k=4 时单步解码吞吐下降约 2.4~2.6 倍；朴素展开使 KV 随 k 线性增长
  • 自投机解码：k=1 草稿、k=4 验证，严格无损加速 1.37~1.71 倍，零外部草稿参数
  • KV 优化：SenseNova 线性注意力 + AWQ 4-bit 权重 + 8-bit KV，256K 上下文约 15 GiB；Dory Last-Loop KV 覆盖，显存钉在 k=1 水平，k=4 精度变化仅 −2.1~+0.4 个百分点

6. Scaling law 与能力边界

  • 隐式计算替代显式 token：k 从 1 升到 4，单任务总输出 token 减少 1.3~2.5 倍
  • 扩展推理深度，不扩展知识容量：SWE-bench Verified 50.3% → 61.8%（胜过 26B 的 Gemma），但事实回忆基准 AA-Omniscience 上 k=1 与 k=4 都是约 10%
  • 收益递减，甜点在 k=2：k=1→2 贡献 +9.2 分，翻倍到 k=4 只再加 +2.3 分

7. 下一步：残差拓扑演进

  • AttnRes / mHC / GR：用数据依赖的注意力重组层间历史；GR 是更便宜的多流替代
  • Loop + Engram：把静态知识挂在不循环的输入块上，补小模型的知识短板
  • 从请求级到 token 级自适应停机，配合 WaveFront Decoding 式混合 loop 批处理
