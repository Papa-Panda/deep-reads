# 全球智能手机出货量第三季度同比降 22% ，创有纪录以来最大降幅，背后是什么原因？

> 知乎热榜条目（约182万热度，63个回答，21.4万浏览）。据IDC初步数据，2026年第三季度全球智能手机出货量降至2.553亿部、同比萎缩22%，创有记录以来最大降幅，导火索是AI热潮引发的存储芯片危机：零部件成本迅速攀升、供应日趋紧张。高赞回答的主线是价格弹性：存储涨价推高整机价格（有回答引IDC预测2026年全球均价涨27.6%），千元机跌幅可达约40%，而高端需求更黏、三星苹果跌幅个位数；量跌而总收入未必跌，利润向上游存储集中。对他正对口：AI算力需求向上游传导、再反噬消费电子的产业连锁案例。注：问题页已在浏览器中核读（63答），细节为回答区观点，未逐条外部核验。
