大纲（据视频简介与章节整理，正片未逐段核验）

  • 目标：老硬件跑几百 G 的 DeepSeek
  • 220 元闲鱼主板 + 双路 E5-2698B v3 + 512GB DDR3 ECC + 2× Tesla V100 16GB
  • 模型 DeepSeek-V4.1-Flash-1017，423GB GGUF 量化（IQ2_XS / IQ3_S）
  • 推理框架 Strata；Ubuntu Linux
  • 关键思路：分层推理 + CPU 内存 offload
  • MoE 专家层在 CPU 与 GPU 之间分工，绕开 16GB 显存墙
  • 512GB 内存承接模型权重，V100 只跑热专家
  • 实测结果：从个位数 Token/s 一路优化上来
  • 单张 V100 约 19 Token/s；双 V100 最高约 33.5 Token/s
  • 400GB+ IQ3_S 模型约 16.7 Token/s；验证 256K 超长上下文
  • 后续计划与局限
  • 计划：双 GPU 协同、专家并行、张量并行
