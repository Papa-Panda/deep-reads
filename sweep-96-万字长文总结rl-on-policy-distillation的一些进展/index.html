万字长文总结RL/on policy distillation的一些进展

知乎收藏的万字长文（YiFan-Zhang，910 赞/1488 收藏），系统梳理 on-policy learning / on-policy distillation 近期 11 篇论文：以 SDPO 为核心，讲清如何用密集 logit 级信号替代 GRPO 的稀疏标量奖励、解决 credit assignment；另含 POPE、Video-OPD、Golden Goose、RLAnything、Search-R2 等。正中他 post-training / Agentic RL Infra 转型主线，公式与机制拆解完整。

2026-09-28 · 作者：YiFan-Zhang（专栏「多模态大模型」）

原文链接：https://zhuanlan.zhihu.com/p/2004506304065065334

大纲

  • 动机：RLVR 的天花板
  • RLVR 只给 outcome 奖励（对/错）；难题上模型写不出正确解 → 完全没有学习信号
  • credit assignment 是 RL 核心难题：只知道"错了"，不知道"错在哪里、为什么错"；GRPO 同组全 0 分时优势函数直接塌缩为 0
  • rubric reward：从 reward signal 角度给更 dense 的反馈，不只看 outcome，对 reasoning 也有细粒度要求
  • on-policy learning：从 token-level 就给出 reward signal，且 annotation-free；两套直觉可兼容——rubric 给 teacher 更多 context，teacher 给 student 更好的 token-level 反馈
  • 核心机制：on-policy self-distillation（SDPO）
  • 同一模型分饰两角：Student π_θ(·|x) 无反馈生成答案 y；Self-Teacher π_θ(·|x,f) 看到 y 与环境反馈 f 后"事后"评估
  • 反馈 f：代码解释器运行时错误（哪一行、什么异常）、未通过测试用例信息、同 batch 成功路径作参考答案
  • 教师不重生成答案，只计算 y 在教师上下文（问题+反馈）中的对数概率——"如果早知道这个报错，你觉得刚才那个 token 选得怎么样？"
  • 优化目标 L_SDPO = Σ KL(π_student || stopgrad(π_teacher))；stopgrad 防教师迎合学生降低标准
  • 与 GRPO 的本质区别：优势函数从稀疏标量奖励 → 密集 logit 级信号，A_t ≈ log π_teacher − log π_student，逐 token 变化，精确指出哪里好哪里坏
  • 开销：教师只需一次前向传播算 log-probs，无需生成文本；比 GRPO 慢约 17%；Top-K（K=100）近似省显存，显存开销几乎可忽略
  • 稳定性：教师参数用 EMA 或与初参插值正则化；对称 JS 散度替代标准 KL，有助于在线蒸馏稳定
  • 关键实验发现
  • 信用分配越稠密效果越好：logit-level > token-level > sequence-level；序列级 SDPO 也明显超 GRPO
  • 自举循环：学生变强 → self teacher 变强 → 更好信用分配 → 学生继续变强（step 80 学生显著超过初始教师）
  • 冻结教师效果不好；共享参数演化需 trust region / EMA 约束
  • 抗灾难性遗忘：offline SFT 在 IFEval、MMLU-Pro 显著下降；SDPO 大幅提升编程能力同时几乎完美保留通用能力
  • 环境报错与参考答案互补且最有效；只给成功解会让分布"死板"（平均熵仅 0.07），多样性下降；学生原始解给进去反而误导教师复读错误
  • text-rich feedback 跳出 RLVR 局限：把 rich feedback 经梯度更新交给 student，不受 context window 限制，可尝试几千次、记住所有"教训" → continual learning
  • 其余 10 篇速览
  • On-Policy Self-Distillation for LLM：teacher 带 reference 的 cot+answer，loss 用 JSD
  • POPE：难题用专家解答小段前缀作"特权引导"拼进 prompt，让 on-policy rollout 更易采到正确解；1:1 混合原始/带前缀难题；迁移靠 long-cot 的回溯与状态重叠；混入 1000 简单题后难题 Pass@1 维持 14%（相对普通混合 +524%）
  • Self-Distillation Enables Continual Learning：teacher 看 GT demonstration，Reverse KL + EMA；医疗任务上 SFT 把推理能力"压扁"（准确率 31.2%→23.5%，长度 4612→3273 token），SDFT 不会；代价约 2.5× FLOPs；模型越大 SDFT 优势越明显
  • Video-OPD：视频场景的 on-policy distill；TRPV 预验证教师可靠性 + DBTP 按轨迹分歧优先级训练；训练成本约 GRPO 的 20%，数据池 9.6 万条实际只用 2500 条训 1 epoch
  • Text Feedback：训练有多轮反馈、推理只有单轮的 mismatch；RLTF-SD 把"看到反馈后的第二次输出"当隐式示范蒸馏给单轮策略；RLTF-FM 让模型学会预测反馈作辅助任务
  • Golden Goose：把不可验证的互联网文本自动转成 MCQ 式 RLVR 任务（挖关键推理片段、8 个干扰项、字符串匹配判分）；构建 GooseReason-0.7M；9 选项中等难度题梯度信号最高效
  • RLAnything：环境-策略-奖励模型三者闭环联合优化；step-wise 奖励 R = O_τ + λ·平均逐步评价；奖励模型靠"乘积一致性"自校准；环境按难度 acc 自适应改题
  • Meta-Experience：从正负轨迹定位分叉点 s，生成批判 C 并抽象为启发式规则 H；元经验 M=⟨s,C,H⟩ 经回放验证后自蒸馏内化；联合目标 J = J_RLVR + J_MEL
  • Teaching LLMs to Ask：信息不全时先消歧前置条件再规划；候选动作标注前置条件满足/违反/不知道
  • Search-R2：agentic credit assignment；Meta-Refiner 做全局判定 + 局部定位剪切位置 k，cut-and-regenerate；混合奖励 R = r_outcome·(1+r_process)；n=5+一次修补打过 n=10 纯 rollout
  • 作者总结：on-policy distill 样本效率高、速度快、泛化不差、不遗忘；text/environment feedback 作 training signal 的两个作用——让 reward 更 dense、让难题有成功 case
