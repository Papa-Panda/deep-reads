# 如何评价秦朔发文《可怕的红果与中国互联网的字节时间》？

> 知乎热榜问题（热度 297 万；问题页已经登录浏览器通读核验：199 人关注、112,088 次浏览、57 个回答；秦朔原文首发于虎嗅）。秦朔援引野村证券与 QuestMobile 数据发问：中国互联网是否正从「腾讯时间」切换到「字节时间」——2026 年 7 月 Top 50 App 使用时长中抖音 19.4% 首次超过微信 18.8%，字节系合计 40.9% 对腾讯系 29.1%；红果免费短剧 DAU 1.68 亿、同比 +107%，超过腾讯视频、爱奇艺、优酷、芒果四大长视频总和，总时长已居全国第四，人均单日 125 分钟。10 月 28 日抖音副总裁李亮公开回应称文章有「常识性错误」。高赞回答四个角度：注意力经济并非字节发明、算法优先的低社交生态位是结构必然；字节生态协同（抖音分发、番茄 IP、豆包入口）与用户时间失控的行为经济学问题；「红果的胜利是 AI Slop 的胜利」；以及时长份额不等于价值份额、微信的社交图谱与支付仍是另一套护城河。正对他看平台竞争与商业模式的胃口。
