如何看待 DeepSeek 开源的大规模云服务推理框架 DeepInfer ？

知乎热榜条目（522 人关注、约 52.7 万浏览、134 个回答；已通读问题页官方公告与默认排序前 5 个高赞回答）。DeepSeek 把生产推理框架 DeepInfer 开源（Apache-2.0，同步 deepseek-recipe）：本质是只跑 V4.1-Flash 的专用离线引擎，以 vLLM 为出身、集成 FlashMLA/DeepEP/DeepGEMM、MoE EP+EPLB、DSpark 推测解码与批次不变/确定性采样，官方自报单集群日吞吐 155 万亿 Token、每卡每小时 38 美元（谷价）。最有分量的批评也来自高赞回答：开源版缺 KV 缓存系统、PD 分离与跨副本负载均衡，官方经济性靠的正是未开源的这一层。对他是推理 infra 的一手材料，好看点在并行/调度细节与这条交付边界。

  • 官方事实（问题描述）
  • 开源 DeepInfer（大规模云服务推理框架）+ deepseek-recipe（与官方 API 行为对齐的 token 编解码）；承诺后续新模型推理代码继续在此开源
  • 官方自报：基于该框架的 V4.1 Flash 服务单集群日吞吐 155 万亿 Token、每卡每小时收入 38 美元（谷价）
  • 它是什么（回答共识）
  • 模型专用离线推理引擎：目前只跑 V4.1-Flash，把此前开源的算子库接成一个可运行的整体，而非通用多模型框架
  • 以 vLLM 为主要出身，借鉴 SGLang 与 TensorRT-LLM，Apache-2.0；仅支持 SM100 与昇腾 950（GCC 13 / Python 3.12 / CUDA 13 或 CANN 9.2）
  • 技术构成
  • 算子：FlashMLA、DeepGEMM、DeepEP、TileKernels/TileLang
  • 并行与调度：Attention DP、Balanced CP、MoE EP + EPLB（热点专家复制/重排）、异步零开销 batch 调度
  • 解码：DSpark 推测解码；SWA Bounded Replay（prefill 只重算有界后缀，V4.1 默认 140 token）；结构化输出（regex/JSON Schema/EBNF）
  • 一致性：批次不变推理与确定性采样（目前仅英伟达侧）——对评测、合成数据与 RL 的可复现性是实质卖点
  • 最有分量的批评（酷猫本猫，恋猫附议）
  • 开源版只有离线推理；完整在线服务所需的 KV 缓存系统、Prefill/Decode 分离、跨 DP 副本负载均衡三件套未包含，而官方数字恰是靠这一层取得的
  • README 性能图为 prefill 4 卡 + decode 64 卡；复现官方经济性约需 68 卡加未开源的服务层，短期受益者主要是自有整柜机器且锁定 DeepSeek 模型的团队
