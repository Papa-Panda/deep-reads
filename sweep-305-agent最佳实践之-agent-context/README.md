# Agent最佳实践之：Agent Context

> 一年多用 Claude Code、Codex 等编码 Agent 的实践提炼：把 Agent 的工作目录（agent context）与代码仓库分开——代码是输出，context 是记录与日志；用 git 管理，30 人部门共用一个 context、1500+ commits，交接工作就像交一个目录。值得他看的是它把「怎么用 Agent」变成可设计、可操作的协作协议，且附公开模板。
