【RL 入门到 GRPO 18】GRPO 到底改了 PPO 什么？去掉 Critic、换成组内基线、KL 进损失

58 秒把 GRPO 对 PPO 的改动讲到公式级：删掉与策略等大的 Critic；同题采样一组答案，用组均值与标准差算优势（G=64）；KL 不进奖励、以 k3 估计量直接进损失（β=0.04）。还点出一个常被漏掉的细节——每轮只更新一次使 ratio 恒为 1、clip 失效。短而密，适合他做 RL 配方对照。注：字幕轨错配，大纲据 UP 简介整理。

大纲

大纲（据 UP 简介整理；58 秒短视频，简介本身即完整提纲；字幕轨错配不可用）

  • 动机：PPO 的 Critic 与策略模型一样大、还带优化器状态，是 LLM 上最贵的部分，GRPO 直接删掉
  • 优势估计：同一 prompt 采样一组答案（DeepSeekMath 用 G=64），优势 =（得分 − 组均值）/ 组标准差，整条答案共享同一个优势；本质是经典 baseline 思想把基线换成组内均值
  • 与 PPO 逐项对照：公式几乎一样（ratio × 优势、clip、min），真正的差别只有两处
  • KL 的处理：不折进奖励，而是以 k3 估计量直接加进损失，β = 0.04
  • 易漏的细节：DeepSeekMath 每轮采样后只更新一次，新旧策略相同，ratio 恒为 1，clip 无从触发（呼应系列第 9 集的 on-policy 边界）
  • 一句话总结：GRPO = PPO − Critic + 组内基线 + KL 进损失；下集预告 Dr. GRPO / DAPO 的两个偏差
