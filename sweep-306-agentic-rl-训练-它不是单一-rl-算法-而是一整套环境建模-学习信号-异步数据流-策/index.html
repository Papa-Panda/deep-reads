Agentic RL 训练：它不是单一 RL 算法，而是一整套环境建模、学习信号、异步数据流、策略优化和基础设施的协同系统

长文框架综述：Agentic RL 不是换个 PPO/GRPO 变体，而是长时程、调工具、部分可观测、异步执行的系统性策略学习；提出三个不变量（可探索策略空间不坍缩、学习信号不退化、分布偏移可控）与八个方面，贯通 Kimi、MiniMax、GLM 的技术报告与 DAPO、TITO、CISPO 等机制。值得他看的是它把 Agent RL 从算法选择还原为环境、信号、分布与系统的闭环，正对后训练主线。

大纲

大纲

  • 立论：Agentic RL 已从单轮文本优化转向系统性策略学习
  • 关键信号不是更好的 PPO/GRPO 变体，而是长时程 Agent RL
  • Kimi K1.5/K2/K2.5、MiniMax M1/Forge、GLM-5 的技术报告是证据基底
  • 核心问题：如何从真实在线交互轨迹中持续制造可用学习信号
  • 为什么与传统 RLHF/RLVR 不同
  • 训练对象是交互式策略，不是 prompt→答案映射
  • 状态由历史、工具返回、环境反馈、记忆与上下文构成
  • 动作含工具选择、参数、上下文压缩、子任务分派
  • 奖励延迟、稀疏、复合（正确性+效率+token 成本+单位时间训练效率）
  • rollout 时长极不均匀，同步训练昂贵、异步训练引入分布漂移
  • 三个不变量（相互耦合、彼此张力）
  • 可探索策略空间不早坍缩：任务分解、工具顺序、记忆策略、停止条件、自我纠正路径都要存活，不只是 token 熵
  • 学习信号不退化：不同 rollout 可比较，优势不坍缩为零（全对/全错组即失效）
  • 分布偏移可控：rollout 分布、学习器更新分布、真实部署分布三者偏移受控
  • 八个方面
  • 环境与接口建模：结构保真重于表面真实；验证器薄弱导致奖励 hacking；下一代环境扩展是任务/验证器/脚手架三个「编译器」问题
  • 探索与多样性：探索是支撑集管理问题，不是温度；SFT 压缩分布，Pass@1 升而 Pass@k 塌
  • 算力分配与信号策展：均匀分配系统性制造全 0/全 1 退化组；RL-ADA、GVM-RAFT、VIP、Knapsack RL、Reinforce-Ada
  • 目标与策略优化：先诊断瓶颈（梯度噪声/漂移/目标失配）；ReMax、mirror descent、token 级裁剪、CISPO、TITO、双边重要性采样
  • Rollout 采样与异步调度：调度是算法的一部分；partial rollout、Rollout Manager、Windowed FIFO、异步生成-训练解耦
  • 奖励、验证器与效率约束：奖励规定「怎么干」而不只是「对不对」；GRM 多 rubric、Toggle、GenRM 长度偏置、混合奖励、完成时间奖励
  • 记忆、层级与并行 Agent：被训对象是「操作系统策略」而非 token 策略；Context Rot、keep-recent-k、Agent Swarm/PARL
  • 基础设施：infra 塑造训练分布、决定配方在真实成本下是否可扩展、决定训推一致性
  • 结论：真正的竞争是环境、信号、分布、系统的闭环
