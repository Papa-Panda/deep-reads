  • 思路：向人脑记忆与存储借方法
  • 区分该记住什么、该压缩什么、该丢弃什么
  • 用存储与组织策略代替无差别堆上下文
  • 方案落点：上下文优化
  • 目标一：给智能体连续、完整的过往（演示中称作“完整的童年”）
  • 目标二：同样效果下花更少的 token
  • 对 agent infra 的启示
  • 记忆层是可设计的一层：摘要、存取、遗忘策略都影响行为连续性
  • 演示载体是陪伴角色，但问题本身通用：任何长程 agent 都要回答记忆怎么存、怎么取
