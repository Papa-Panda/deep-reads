为什么 GPT-6 Astra 玩《我的世界》被炸毁进度后连续数小时种植土豆？这种异常行为怎么产生的？

47 答、61 万浏览：GPT-6 Astra 在《我的世界》攒 50 小时的进度被苦力怕炸毁后，连续数小时只种土豆、不再下矿。前三高赞给出三层机制解释——记事板被防御性准则冲没目标（赛博 PTSD）、错误记忆占用注意力导致 token 暴涨、长程压缩过度致任务漂移。Agent 长程任务的记忆/压缩/目标保持问题，与他做的 Agent RL harness 可直接对照。仅读到默认排序前 3 答全文。

大纲

  • 事件：GPT-6 Astra 玩《我的世界》，50 小时进度被炸毁后只种土豆
  • 50 小时攒下 6 烈焰棒 + 3 末影珍珠（半自动烈焰人农场）
  • 苦力怕贴脸自爆：炸死 Astra，同时炸毁箱子和床（重生点失效）
  • 掉落物 6000 游戏刻（约 5 分钟）后清除；Astra 思考 12 分钟才赶到，全刷没了
  • 解释一（酱紫君，2247 赞）：上下文被防御性准则冲没
  • 记事板写满防御性准则：随身带关键物资、甘蔗不是苦力怕、别追深粉色像素（猪）
  • 防御性思考挤占上下文 → 最初目标丢失 → 龟缩种土豆维持生存率
  • 比喻：赛博自闭症 / PTSD；走不出记事板小世界 → 无新正反馈 → 准则越堆越多
  • 解释二（星空灵核，1221 赞）：注意力机制视角
  • 错误记忆（小本本）在思维链里反复复述 → token 消耗暴涨
  • 注意力被历史错误占据 → 行为保守化，符合注意力逻辑
  • 现实对照：训斥 flash 模型后 agents.md 堆满不应该条款
  • 解释三（391 赞）：过度压缩 → 任务漂移
  • 长程任务压缩几轮后 → 过度设计 + 防御性编程
  • 种土豆 = 压缩后的安全默认行为
  • 对他的价值：Agent RL / harness 的长程记忆与目标保持
  • 记事板 = 外部记忆；压缩/总结策略如何避免目标漂移
  • 防御性准则的正反馈陷阱：局部安全 vs 全局目标
