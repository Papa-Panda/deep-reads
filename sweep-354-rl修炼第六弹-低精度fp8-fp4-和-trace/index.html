大纲

大纲（全文已通读；大海无量，专栏「学习强化学习」第六弹，2026-11-05；22 赞 / 37 收藏）

  • 背景：为什么 rollout 要低精度
  • RL 每步大头是 rollout，受显存容量与带宽限制
  • 低精度省权重显存（更多 KV Cache、更高并发）、省 decode 读权重字节，支持硬件上还能加速 prefill
  • 代价是训推差异：重要性采样失准，严重时训练崩溃，需测量与修正
  • 通用流程：训练侧保留高精度主权重，每次同步时量化给 rollout，推理引擎原样加载
  • 训推的三种精度配置
  • A：高精度训练 + 低精度 rollout，差异最大但最简单，FP8 下默认推荐
  • B：QAT + 低精度 rollout，前向 fake-quantize 再反量化，反向 STE 直通，4-bit 基本必需
  • C：低精度训练 + 低精度 rollout，前后向 GEMM 直接走低精度 Tensor Core，训练更快但与部分 optimizer offload/ checkpoint 方案冲突
  • B 与 C 互斥；优化器恒更新 FP32 主权重，checkpoint 恒存高精度权重
  • 格式一览：FP8 与 4-bit
  • 元素编码：E4M3（±448，精度优先）、E5M2（±57344，范围优先，仅反向梯度）、E2M1（±6，仅 15 个非均匀码点）、INT4（均匀 16 级）
  • 量化方案：FP8 块 W8A8、MXFP8、INT4 W4A16、MXFP4 W4A8、NVFP4 W4A4；权重显存相对 BF16 约省 2× / 3.9× / 3.8× / 3.6×
  • MXFP4 vs NVFP4：同为 E2M1 元素，区别在块大小（32 vs 16）与 scale（E8M0 只能取 2 的幂 vs E4M3 + FP32 全局 scale 两级）
  • scale 怎么算
  • 通则：取块 amax，缩放到格式量程再舍入；差别在 scale 自身的存储格式
  • FP8/INT4 单级 scale；MX 系列 scale 只能是 2 的幂（块最大值常远离量程上限，浪费码点）
  • NVFP4 两级 scale：全局放大因子 g + 每块 E4M3 scale，是目前最精确的 4-bit 浮点方案
  • 量化粒度：per-tensor、per-group（沿 K 维）、2D 块（FP8 权重 128×128，转置后仍可共用 scale）
  • 硬件决定计算路径
  • Hopper 只有 FP8 Tensor Core，4-bit 只能省显存带宽、省不了算力；Blackwell 才有 FP4 Tensor Core
  • 数据中心卡与消费级卡指令不同，kernel 不可互换；同一格式在不同硬件上可能走不同 kernel、算出不同数
  • 量化哪些层
  • 路由专家必量化（占 MoE 参数 90% 以上）；注意力/dense MLP/共享专家 FP8 可量、4-bit 一般留 BF16
  • lm_head、embedding、router、norm、视觉编码器、MTP 层恒留 BF16；TP 切分须整除块尺寸，否则改用 EP
  • KV Cache 精度独立配置，FP8 KV 使容量翻倍
  • QAT：让训练看到 rollout 的权重
  • 前向：每步由 amax 重算 scale，量化再反量化得到实际参与 GEMM 的权重；反向 STE 把梯度直通回 FP32 主权重
  • DeepSeek-V4.1 实际配方：专家 W4A8，训练前向 FP32→MXFP4→反量化到 FP8 做 FP8 GEMM，rollout 原生 MXFP4；主 KV Cache 也加 QAT
  • 效果：MXFP4 专家训推差异降约 3–6×；NVFP4 W4A4 的 QAT 只能降 10%–30%，因 fused FP4 kernel 与反量化后高精度 GEMM 的数值差异无法被 fake-quant 模拟
  • 训推差异：测量与修正
  • 先测量：低精度 rollout 跑一批 prompt 记 logprob，训练侧重算同一批序列，用 KL（k3 估计器）、logprob 绝对差、相关系数比较；训练中持续监控
  • 再修正：TIS 截断重要性采样（常用 cap C=2，低精度 rollout 必需）、QAT/低精度训练、router replay、敏感层留 BF16、固定 kernel 后端
  • TRACE：用 rollout 的码点指导训练侧舍入
  • 问题：两端各自量化误差都小，码点却可能分叉——输入只差 0.48，跨过舍入边界后输出可差 24（放大 50×）；FP4 相邻码点差 33%–50%
  • 方法：候选仍是训练激活夹住的相邻两码点 q−/q+，改按 rollout 的实际码点选最近者；逐点不比 RTN 更远
  • 指导信息：只存 1 bit 尾数 + scale（相邻码点仅最低尾数位不同），且只存后一半层，7.5 KB/token，约省 6×
  • 实验：Qwen3.5-35B-A3B 联合 NVFP4 权重/激活 + FP4 KV，TRACE 平均 75.3（BF16 74.9，QAT 59.6，QUADS 68.8）；128K 输出 decode 吞吐最高 5.4×；端到端步时仅 +7.4%
  • 小结
  • 训练留高精度主权重、rollout 用低精度，省显存带宽但引入训推差异
  • FP8 最成熟；4-bit 一般只动路由专家且几乎总要 QAT
  • QAT 让训练前向看到 rollout 的量化权重；FP4 下只对齐格式不够，舍入结果也要一致
  • TRACE 把「格式对齐」推进到「舍入对齐」，代价是记录/传输指导信息与约 7.4% 端到端开销
