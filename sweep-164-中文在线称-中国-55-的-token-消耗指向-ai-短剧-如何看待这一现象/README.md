# 中文在线称，中国 55% 的 token 消耗指向 AI 短剧，如何看待这一现象？

> 知乎热榜第 1（约 546 万热度，226 个回答，约 62 万浏览）。中文在线 2026 年 6 月机构交流披露的中国 token 消耗构成出人意料：AI 短剧与视频生成占 55%、电商营销 24%，被寄予厚望的软件开发（vibe coding）只有 15%。头部回答（323 赞）给出了机制解释：视频 token 是按时长计的——720p 约 2 万 token/秒，一个 5 秒镜头约等于一部 10 万字剧本的量，加上反复重抽，成品轻松到数亿 token，所以 55% 甚至偏低；但他同时提醒，token 份额不等于算力、收入或价值份额，视频 token 定价完全不同。对他的价值在推理需求结构：若需求大头在内容生成而非编程与 agent，推理 infra 的优化重心（视频/多模态吞吐）就要跟着改。数据须打折：55% 是单一公司披露、无统计口径，披露方本身做 AI 短剧。注：已读默认排序前 3 答（最高赞 495 的是短讽刺答，机制答在第二）。
