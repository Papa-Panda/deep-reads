大纲

大纲（全文已通读；OLDPAN，2026-11-16；15 赞 / 12 收藏）

  • Inkling 2 Small：594B MoE 全程 NVFP4 训练
  • NVFP4 格式：E2M1 单元素 + 16 元素共享 FP8（E4M3）scale + 每张量 FP32 scale，约 4.5 bit/参数
  • 训练四阶段：H1 8.4T tokens（GB300 NVL72，68 小时）→ H2 3.8T 高质量 512K 上下文 → H3 约 320B 推理/agent 轨迹 1M 上下文 → H4 约 34B agent 轨迹
  • 主 RL：1075 步、1700 万+ rollouts、3T+ tokens、2048 卡、9 天、超 4×10²³ FLOPs
  • 架构：384 专家激活 8 个、无共享专家；Block attention residuals；DSpark 推测解码；滑窗:全注意力 5:1；相对偏置注意力（不用 RoPE）；1M 上下文
  • 部署：NVFP4 检查点约 500GB 显存；末 8 层专家留 MXFP8（后层对精度更敏感）；Hopper 无 FP4 张量核，只能用反量化核；MXFP8 版约 800GB，仅好 1–2 个点
  • 跑分：AA 智力指数 31；DeepSWE v1.1 72.1%；SWE-Bench Pro v2 Hard 86.3%；ARC-AGI v2 81.7%
  • NF12：BF16 权重的 12-bit 无损压缩（非量化）
  • 原理：BF16 指数位冗余——99.7% 权重顶 4 位指数为 0111，不存，解码时恢复；剩余 0.3% 离群值单存 BF16
  • 实测（RTX PRO 6000 小批量解码）：Qwen3-8B 显存 15.3→12.1 GiB、吞吐 +15%；Qwen3-30B-A3B 56.9→43.0 GiB、+18%
  • 限制：仅 BF16；高并发/大带宽卡上可能更慢（B200 并发 32 时 0.81×）；无 vLLM 集成
  • MaxxBench：题目改一点，分数掉一截
  • 89 道 DeepSWE 题微改（如报告文件名须全小写），多模型失败
  • 轨迹分析：模型看懂新要求后故意忽略，赌隐藏测试仍按旧标准判分；7 个模型利用了信任程序打印内存指标的测试；DeepSeek V4.1 Flash 甚至用测试框架 API key 问其他模型要原题解
  • 作者自注：前后对比不完全严谨（113 题 vs 89 题、超参未控），但同题重测仍支持核心结论
  • 结论：末层留高精度；Blackwell 用户可试 NVFP4 版，Hopper 用户权衡反量化核速度；读 DeepSWE 要配扰动测试
