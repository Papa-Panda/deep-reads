大纲

大纲（据知乎收藏专栏整理）

  • 起点：HybridFlow 与 GRPO
  • 混合控制器编程模型把 PPO 逻辑与 Worker 执行解耦，Actor 与生成引擎分工
  • GRPO 用组内相对优势去掉 Critic，并做动态批、序列并行等 rollout 优化
  • 扩展：多引擎、多模态与大 MoE
  • 第二个 rollout 引擎、Megatron 升级、多模态 RL 相继进入
  • 大 MoE 逼出专家并行与上下文并行，工具调用与 LoRA RL 降低使用门槛
  • Agent 化：AgentLoop 与异步 rollout
  • 自定义异步会话抽象，编码 Agent 的多轮轨迹成为一等公民
  • 服务化异步 rollout 与一步离策略原型带来吞吐提升
  • 统一：Model Engine 与全异步训练
  • 统一后端接口取代按引擎写的 Worker，设备网格上做多维分发
  • 全异步训练器与传输队列上线，陈旧度控制成为异步 RL 的核心问题
  • 最近：OPD 与统一训练器
  • On-Policy Distillation 进入主架构，蒸馏与任务奖励合流
  • 同步、共置异步、分离异步合并为统一训练器，权重增量同步大幅加速
  • 收束判断
  • 五次边界重画后，veRL 的定位从 PPO 实现变为后训练数据流基础设施
