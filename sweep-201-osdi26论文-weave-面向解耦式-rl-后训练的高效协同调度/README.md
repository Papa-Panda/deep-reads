# OSDI26论文--Weave:面向解耦式 RL 后训练的高效协同调度

> 知乎推荐流条目（想飞的石头，2026-08-30编辑，23赞、约29收藏）。OSDI'26 论文精讲：解耦式 RL 后训练把 rollout 放便宜的 H20 池、训练放 H800 池，但 on-policy 严格同步造成依赖气泡、两池轮流闲置，朴素解耦的成本反而高于共置 veRL。WEAVE（港科大+阿里，基于 ROLL 实现）用协同执行组加两级调度把一个任务的气泡用另一个任务的活跃阶段填满——组间按最坏情况保守放置守 SLO，组内用可证明最优的轮转加长尾迁移，状态驻留主机内存实现热启动。在 328×H20 + 328×H800 测试床上成本效率达 1.84×（对朴素解耦）与 1.38×（对共置 veRL），100% SLO 达成。对他正对口：这是 RL 后训练集群调度的一线系统论文，讲透解耦架构的成本账。注：已通读知乎原文，并核对了论文原文。
