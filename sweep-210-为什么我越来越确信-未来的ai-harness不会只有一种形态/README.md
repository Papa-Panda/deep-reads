# 为什么我越来越确信，未来的AI Harness不会只有一种形态？

> 知乎推荐流条目（浅月落，2026-10-15 发布；热度很低，0 赞、2 收藏、约 208 阅读）。作者复盘自研轻量 Agent 框架 SIAH 的实践后提出一个判断：Harness 的形态应由任务的复杂度与不确定性决定，而不是追求单一通用框架——简单任务用单循环 ReAct，复杂任务用先规划后执行，多视角任务用多 Agent 协作，高风险任务保留 Human-in-the-loop；Skill 也应分临时经验、领域方法论、组织资产三层沉淀。对他的价值在 Agent infra/harness 这条主线：这是一篇把 harness 多样性讲成选型原则的一线实践随笔。注：全文为框架与观点论述，无 benchmark 与成本数据，深度在结构而非实测。
