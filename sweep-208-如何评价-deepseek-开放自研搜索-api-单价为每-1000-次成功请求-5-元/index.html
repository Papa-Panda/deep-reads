如何评价 DeepSeek 开放自研搜索 API，单价为每 1000 次成功请求 5 元？

知乎热榜条目（约 82 万热度、51 个回答）。DeepSeek 把自研搜索引擎正式开放为 API：其网页端与 API 端搜索长期由该引擎支撑、每天处理数亿次请求，索引全球千亿级网页、多语言，并以识别机制过滤 SEO 作弊、GEO 操纵与低质 AIGC；本次新增 Search 与 Fetch 两个接口，均为每 1000 次成功请求 5 元。对他有用：这是 AI 原生搜索基础设施的定价与开放策略一手材料，关系 Agent 的检索层成本结构。注：已读热榜问题页所载官方发布原文，未读到高赞回答细节。
