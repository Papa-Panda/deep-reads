# 更快更省的 RL 权重同步传输

> 实习作者做的 RL 权重同步中间件 ShardFly：零冗余发送计划（算一次、每步复用）+ GPU 发起网络（NCCL device API 绕开 CPU）+ 传输中量化（BF16→FP8→FP4），256 张 H20 上 Qwen3-30B-A3B 同步从 2953.6ms 降到 373.9ms（7.9x），端到端训练 20.4 分钟→3.5 分钟。值得他看的是它正撞 RL 训练 Infra 主线，把“同步耗时 3 倍于训练步”的瓶颈打成可忽略项，且有论文（arXiv:2611.00646）与开源代码可对照。注：文中 TL;DR（3.59–11.02x）与表格最大值（11.07x）有小出入；FP4 对下游精度的影响尚未充分验证，仅在 H20 上测过。
