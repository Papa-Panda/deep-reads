从混合精度到统一 FP8 RL：Moving Beyond Mixed Precision for Stable and Accelerated MoE RL

多团队工程报告（InfiXAI、蚂蚁 AQ、SGLang RL、slime，2025-11-19）：把 FP8 推进 MoE 模型 RL 训练，先以对照实验归因 KL Loss 异常来自前向量化误差而非实现 bug，再在 Qwen3-30B-A3B 与 Qwen3-235B-A22B 上验证 FP8 的 TIS clipfrac 更低、训推 logprob 差更窄，且模型越大优势越明显；正撞 RL 训练与量化主线。

大纲

大纲（全文已通读；Chayenne Zhao，多团队工程报告 InfiXAI / 蚂蚁 AQ / SGLang RL / slime，2025-11-19，239 赞 / 249 收藏）

  • 硬件基础：FP8 为什么能加速
  • Tensor Core 演进：Volta FP16 312 TFLOPS → Blackwell Ultra FP4 3670 TFLOPS
  • FP8 格式 E4M3（7.46e-2 ~ 448）与 E5M2；量化需 scale，团队选 FP32 scale 而非 MXFP8 标准的 E8M0
  • 量化公式：逐 token scale S = max|X| / Vmax，Q(x) = round(x/S)
  • FP8 训练难点
  • 显存/计算开销：TE 保留转置权重副本与高精度激活副本；小 batch 时 CPU 成瓶颈
  • 精度对齐：FP8 与 BF16 每次 GEMM 误差约 0.0007
  • 工程坑：TE 版本兼容、MLA 支持、优化器 offload 冲突
  • KL Loss 异常归因：是 bug 还是量化误差
  • cuBLAS vs DeepGEMM 单 GEMM 误差对比（约 0.00068 vs 0.00036–0.00065，logit 尺度约 10）
  • Qwen3-4B + H800 假量化实验：误差来自量化本身，与 GEMM 实现无关
  • 四组对照 Case 1–4：前向量化误差主导，训练侧权重/激活量化贡献小；TIS-clipfrac 能度量影响
  • 结论：FP8 的 loss 与 TIS-clipfrac 变化与量化误差自洽，不是 bug
  • MoE 模型上的验证
  • Qwen3-30B-A3B（2×H20）与 Qwen3-235B-A22B（16×H20）
  • FP8 RL 的 TIS clipfrac 更低，训推 logprob 差更窄；MoE 越大，FP8 优势越明显
  • 规模效应：30B → 1TB，clipfrac 与 logprob diff 都随规模增长
  • 未来工作
  • TE-native 全 FP8、FP8 master weights、权重压缩、FP8 KV cache、FP8-native GRPO、全 FP8 RL 训练
