面向 SGLang 的 Profile Analysis SKILL: 3 张表定位 Kernel Fuse 和 Overlap 机会

BBuf 做的 SGLang Profile Analysis SKILL：把 torch profiler 的 trace 归纳成 kernel 表、overlap 机会表、fuse 模式表三张表，定位新模型在 SGLang 上的 kernel 融合与重叠优化点；Qwen3.5-4B 与 gpt-oss-20b 的 H100 实测演示，外加 H100/H200/B200 上 Torch Compile 的跷跷板对比。值得他看的是它把“新模型冷启动性能分析”做成可复用的 agent 工作流，正撞推理优化与 SGLang 内核主线，且附开源 SKILL 可直接用。

大纲

大纲（全文已通读，BBuf，编辑于 2026-04-21）

  • SKILL 是什么：triage-only 的 SGLang 性能分析工作流
  • 单一入口 analyze_sglang_torch_profile.py，输出固定三张表
  • 输入：现有 trace.json（.gz）/ profile 目录，或直接对运行中的 SGLang 服务触发 profiling
  • 支持单 trace、双 trace 对照、按 prefill/decode 分阶段、扩散模型
  • 目标：给 Claude Code / Codex 用，省冷启动 profiling token，新模型分析更深更全
  • 安装：github.com/BBuf/SGLang-Auto-Driven-SKILLS 或 SGLang 仓库内 .claude/skills/sglang-torch-profiler-analysis
  • 三张表分工
  • Kernel 表：每个 kernel 的 GPU 时间占比（默认只列占比≥1%的行），映射到 Python 源码路径与 CPU op
  • Overlap 机会表：按独占/被隐藏时间占比、依赖风险、kernel 类别判定重叠空间
  • Fuse 模式表：模式注册表 + 目录确定性匹配源码，不做模糊字符串匹配；匹配不足时可附 AI 相似度判断（高/中/低）
  • 模式库覆盖 SGLang、vLLM、FlashInfer、TensorRT-LLM 已有 fuse/overlap 模式，含未合入 PR
  • 扩散模型有后端门：若回退到 diffusers 后端则停止分析，定性为后端选择问题
  • 演示一：Qwen/Qwen3.5-4B（H100 decode，Codex + GPT-5.4）
  • 主导 kernel 是 nvjet FP8 GEMM：最大 9.23ms / 24.0%（lm_head），另两路 16.4% 与 15.1%
  • Overlap 表：独占时间约 99–100%、被隐藏时间近 0，属 headroom；P1 行建议试融合，P2 行先查依赖
  • Fuse 表头名：PR #22392 用 CUTLASS FP8 scaled MM 替换 nvjet，Likely，覆盖 27.61ms / 71.7% 相关 GPU 时间（去 memset 气泡与多余拷贝）
  • 其他 Likely 模式：融合 QK RoPE reshape + KV cache 写入（2.5%）、DSV3 router GEMM（2.4%）、残差加 + RMSNorm 融合（2.2%）、激活与乘法 / SwiGLU-GeGLU 融合（1.1%）
  • 演示二：openai/gpt-oss-20b（H100 prefill + decode）
  • Prefill 由 MoE matmul 主导：_matmul_ogs 两路占 35.6% 与 23.0%；decode 为 21.3% 与 13.1%
  • Fuse 表头名：vLLM 来源的 DSV3 router GEMM，Likely，prefill 64.9%、decode 43.6%
  • PR #22392 同样显著：prefill 22.1%、decode 36.1%
  • 为什么不用 Torch Compile：三硬件实测跷跷板
  • H100：12 个扩散模型全改善（+0.81% 至 +10.43%，hunyanvideo +10.43%）
  • H200：多为正向，但 ltx2 -4.30%、wan-i2v -2.11%、helios -0.26%
  • B200：分化剧烈，flux +13.75%、wan-ti2v +18.20%，但 qwen -10.26%、zimage -53.15%、ltx2 -26.60%
  • 结论：Torch Compile 在不同硬件上频繁且严重跷跷板，视频模型编译时间人等不起；agent + SKILL 可提供图级 fuse/overlap 能力而不必用它
  • 下一步：按 SKILL 结果试 fuse/overlap、验证有效后提 PR
