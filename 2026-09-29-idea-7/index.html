CPU 与虚拟机

讲清 socket / core / thread / vCPU 四级概念、hypervisor 时间片调度、硬件虚拟化与资源隔离，划出 CPU 超分的安全边界；附 VM 容量估算器，同时算 CPU 上限与内存上限、定位瓶颈，并按预留 20% 给出建议起始数量。

大纲

四级概念

  • socket：主板上的物理 CPU 插槽
  • core：物理核心，真正的执行单元
  • thread：超线程，一个 core 虚出两个执行流
  • vCPU：虚拟机看到的 CPU，hypervisor 调度出来的时间片

hypervisor 时间片调度

  • 多个 vCPU 分时复用物理 core
  • 调度延迟与 noisy neighbor 的来源

硬件虚拟化

  • VT-x / AMD-V：CPU 直接支持虚拟化，虚拟机接近裸机性能
  • 内存虚拟化：EPT / NPT，减少影子页表开销

资源隔离

  • CPU 份额与预留：保证与限制是两回事
  • 内存预留与气球驱动
  • IO 限速：磁盘与网络的公平队列

超分边界

  • 超分是什么：分配的 vCPU 超过物理 core
  • 什么时候安全：平均负载低、峰值错开
  • 什么时候塌：长期满载下排队延迟指数级暴涨

VM 容量估算器

  • 输入：物理机 CPU/内存资源、单 VM 规格
  • 输出：CPU 上限、内存上限、瓶颈项
  • 预留 20% 后给出建议起始数量
  • 声明：仅用于容量规划起点，不是 SLA 承诺
