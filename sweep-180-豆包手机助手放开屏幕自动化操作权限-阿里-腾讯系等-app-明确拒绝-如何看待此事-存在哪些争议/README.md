# 豆包手机助手放开屏幕自动化操作权限，阿里、腾讯系等 App 明确拒绝，如何看待此事？存在哪些争议点？

> 知乎热榜条目（约158万热度，30余个回答）。豆包手机助手在屏幕自动化协议（SAEP）公示30天后宣布逐步放开第三方应用的自动化操作权限，阿里、腾讯系等应用已明确声明拒绝。回答区三条主线：权限与安全——系统级接口本可让应用只开放选定能力，直接操作屏幕却意味着智能体可无差别读取界面，代付出错时责任也难界定；收入与入口——智能体绕开开屏广告与付费搜索排名等核心收入，谁掌握智能体谁就掌握流量入口；阵营——拒绝被指带有针对字节的竞争色彩，同类系统级智能体在别家应用上却能自动购物。正对他的Agent infra主线：运行时权限模型即平台话语权，与此前AGENTS.md标准之争是同一条线。
